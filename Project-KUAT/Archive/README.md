# IDEA 设定资料归档

2026-10-04，按白羽奈绪的要求归档进入 K.U.A.T。这里是内部创作资料，不是可公开发布的世界百科。

## 范围与保真

- 26 份：`IDEA/WORLD.md`、`IDEA/记忆——世界观/` 下 23 份 Markdown、`IDEA/记忆——设计/` 下 2 份讨论。
- `Sources/` 保存原始字节（含 frontmatter、换行、原有错字与重复）；`manifest.json` 保存相对来源、SHA-256、大小、原始状态和导入时间。
- 应用“设定档案”提供分类、全文搜索、正文排版和原文正文视图；frontmatter 单独作为来源元数据展示，完整文件保存在 Sources。
- 原来的 IDEA 文件未修改。用户已经编辑的概览也不自动覆盖。
- 小说正文没有在本轮逐章审校或导入；个人资料、第三方文风素材、OCR 环境和工程资料不混入世界设定。
- 文档不是独立实体卡片：暂未拆分为可编辑人物卡、地理坐标、关系连线或唯一剧情时间线。

## 阅读与版本核对

本批阅读覆盖基础世界观、世界历史、场景、人物组织、大纲、事件追踪、补充和设计讨论。归档保留作者答复、旧记录、助手提案各自的语境，源状态 `complete` 不表示作者确认全部内容。

1. **整体与局部**：Project World 是整个架空世界；塔罗斯是《记忆》当前故事发生的星球，不能把二者等同。宇宙底层、当地文明认知、角色所知和读者获知需要分开。
2. **剧情版本**：旧事件追踪记载学院第六章已揭露海德纳事件；设计讨论要求揭露晚于三十章，学院结构秘密延后到第七卷。不能把两种章节规划直接拼成一条时间线。
3. **历法来源**：设计讨论第一部分的作者答复以学院建立为元年，列出诺斯卡尔历 28 年海德纳事件、30 年梅莹事件、33 年伯斯塔事件。源文档的 2026-07-24 是文档日期，不是世界内日期。本次不自动改写概览的历法区域。
4. **数量**：总大纲的夸特集团写 11 个、实际列 13 个；《其他势力与角色》写 13 个。保留差异待统一。世界内夸特集团与本软件 K.U.A.T 分属设定和现实项目。
5. **姓名与代词**：崔卿棱／崔卿菱、希纳／希娜、伊迪亚／伊迪娅存在不同写法。主角团文档的墨凌班级调查段用“她”，而第四章后补充明确星言四人皆为男生。没有全局替换或合并身份。
6. **叙事层次**：星雨身份、塔斯尤尔地点在设定里已有说明，但事件追踪仍以读者视角推测。不能因追踪写“未揭示”就断言作者未设计，也不能把其中猜测当作事实。
7. **经历差异**：雪入学前未见学院老师的描述与伊瑟尔隐身份相识／训练记录，应进一步按面孔与身份区分；罪西与黎的获救过程在大纲和设计讨论里也有不同版本，暂不合并。
8. **链接**：角色全目录引用部分旧编号，如旧 `04_白羽一族.md` 对应当前 `01_白羽一族.md`，旧 `13_诺斯卡尔高等学院_完整设定.md` 对应当前 `10_诺斯卡尔高等学院_完整设定.md`。不改动原文，目前以标题搜索查阅。
9. **作者层**：WORLD 包含底层真相和多轮战力模型提案，存在明确否决、暂缓与待裁决内容；末轮“思路不错，会考虑完善”也不是最终定稿。整个文档默认折叠，未展开时不搜索正文。其他内部设定同样可能含剧情剧透。

## 更新与验证

在仓库根目录执行 `python -X utf8 Project-KUAT/scripts/import-idea.py` 重新从白名单来源生成快照和浏览数据。它只覆盖本目录的生成副本和 `src/archive-data.js`，不回写 IDEA 原文。新增、删除、改名来源应人工核对；脚本不会清理旧副本。

执行 `node --test --test-isolation=none Project-KUAT/tests/model.test.cjs Project-KUAT/tests/archive.test.cjs` 检查源副本、哈希及安全渲染；`tests/archive-ui.cjs` 检查分类、检索、阅读与作者层折叠。

所有归档都不纳入现有 Matrees 导出。作者层开关只是阅读展示控制，并非加密或访问控制；本机程序包含完整内部资料，不能作为公开发行包。
