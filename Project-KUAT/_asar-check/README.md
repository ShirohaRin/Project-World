# Project K.U.A.T

Project K.U.A.T 是 [Project World](../README.md) 的第四子项目，于 **2026-10-03** 确定启动。目标是建立一个完整的**项目管理、可视化与综合创作平台**，支撑架空世界的组织、构思和模拟。

当前阶段：从零建立基础平台，已编写世界概览的早期原型。**没有可供迁移的代码**。目录使用 `Project-KUAT`；K.U.A.T 展开为 Knowledge、Understanding、Application、Transform。世界内定位为夸特集团内部工作平台。

## 运行当前原型

本版本使用原生 HTML/CSS/JavaScript 与 Electron 桌面外壳。先在 Project World 根目录安装共享环境，再启动本项目：

```powershell
.\Install-Environments.ps1
cd Project-KUAT
npm start
```

安装后也可运行 `Start-KUAT.ps1`。运行时使用 Project World 根目录 `Environments/Node/` 下统一安装的 Electron，不依赖桌宠临时目录。共享 Electron 43.7.7 已安装，Windows x64 构建通过，产物为 `release/KUAT-win32-x64/KUAT.exe`；整个目录需一起保留。使用 `npm run package` 可从本地已校验的 Electron 缓存重新构建。

直接用浏览器打开 `index.html` 可查看界面；浏览器数据保存在该浏览器的 localStorage，与桌面数据不互通。桌面版设计为将档案写入 Electron 用户数据目录的 `world.json`。

已编写的功能包括概览阅读、编辑、本地保存、变更记录、JSON 档案导出和待同步内容导出。设定卡片已接入 108 个实体词条，支持新建、编辑、分类、检索、关联及来源核对；来源档案保留 26 份原文快照。关系图与时间线已提供本地编辑功能；地图与插图模块仍待开发。导出待同步内容不会更新 Matrees，也不表示 Matrees 支持该 JSON 格式。

语法检查通过；两项数据模型测试通过（`node --test --test-isolation=none tests/model.test.cjs`）。已启动打包后的桌面程序并读取到完整概览控件；截图工具超时，视觉验收与保存持久化仍需进一步验证。

## 为什么单独建立

世界观管理、创作与模拟原本属于 IDEA 的能力设想。随着内容量扩大，IDEA Assistant 又更侧重生物科研，将全部职责集中在同一个平台会使工作执行与世界构建工具的边界模糊。

K.U.A.T 承接管理与构思这一部分。Project IDEA 继续发展更完善的工作能力与处理能力；主项目侧保留 IDEA 的角色映射与生活助手需求。拆分让两个平台分别围绕各自目标发展，同时服务于 Project World。

## 关系图

关系图直接展示词条 related 关联，重复双向关联合并为一条无向线，不推断语义。支持名称/别名/标签搜索、类型筛选、邻居视图、缩放和平移。选择节点查看详情、跳转设定卡或打开词条编辑器增删关联；保存沿用 entries.json 的版本校验与待同步标记。可导出含关联的完整词条备份。Matrees 同步仍未接入。无关系类型或自定义布局持久化。


关系图自由编辑：拖动节点自动保存本机位置（localStorage，暂不包含在词条备份）；筛选不重新排列其他节点。自由连线模式依次点击两个节点添加关联，Esc 退出；点击连线后可删除，双向关联会一起移除。新增与删除均通过现有词条版本校验保存，标记待同步。重置视图只重置缩放和平移，不清除布局。


力导向布局：使用节点度数加权的反平方排斥、弹簧连线、弱中心引力、矩形碰撞与速度阻尼。度数越高，排斥越强。拖动节点时固定鼠标下的节点，松手继续平衡；支持暂停布局，连线模式自动暂停。后台停止动画，静止后休眠，定期保存本机布局。无固定类型分区。


关系画布更新：默认空白，添加节点从资料库选择，分类为概念、事件、人物、组织、其他设定（地点归入其他设定，原词条类型不改）。可先新建设定，再通过添加节点加入画布。移出画布不删除词条；显示的关系仍来自所选词条的关联。固定状态与位置一起保存，固定节点不响应力和拖动。已移除中心引力与连线弹簧，仅保留度数加权排斥、碰撞、阻尼。成员列表使用本机localStorage，不包含在词条导出中。


右键菜单：空白处添加节点，按右键位置放置（考虑缩放和平移）；节点菜单提供连线、固定/解除固定、查看词条、移出画布。排斥距离上限240画布单位，最后60单位平滑衰减，超出不施力，残余速度按阻尼停止。


稳定性调整：节点没有240范围内的邻居时立即清零速度，不再惯性漂移；边缘60单位内逐渐增强阻尼。没有新增全局吸引力。


距离微调：当前斥力阈值为180画布单位（原240），保留边缘减速和范围外立即停止。


连线力更新：无直接连线的节点仍采用180排斥范围；直接相连的节点改为110，并增加只沿显式连线作用的拉力，目标间距100。保留碰撞保护、阻尼与固定节点，无全局中心引力。相连节点可在排斥范围外受到连线拉力。


全局操作：全局固定一键固定所有画布节点（含筛选隐藏项），新加入节点沿用固定模式；全局放松解除全部固定并恢复物理。可再单独解除或固定某节点。右键发起连线成功一次即退出；工具栏自由连线保留连续模式。


固定语义修正：固定仅禁用力学位移，单独固定与全局固定的节点仍可手动拖动；拖后保持固定，保存新位置和固定状态。


节点选择更新：移除全局固定/放松按钮，暂停布局统一固定所有节点，继续流动统一解除固定，均允许手动拖动。右键或工具栏添加先选五类之一，列表正文点击显示详情；右侧58px选择区内的小方框切换画布成员，选中绿色。五类轮廓：概念六边形、事件斜四边形、人物胶囊、组织切角矩形、其他普通矩形。


暂停语义修正：暂停/继续只控制整个力系统运行，使用独立的paused存储，不修改任何节点pinned。固定节点无论暂停或继续均不受力，仍能手动拖动。新加入节点默认非固定。旧版已保存的固定状态保留，可在节点右键解除。


批量放置：选择器仅暂存勾选，右下角确定添加才修改画布，关闭即放弃。单个节点位于右键坐标；批量节点在该位置生成可拖动临时框，按三列排列。框内节点不参与力学，拖出框外即释放，空框自动消失；临时框与位置一并本机保存。


画布优先界面：关系图占满页面主体，工具栏与详情浮层展示；单击空白取消连线。滚轮上下、Alt+滚轮横向、Ctrl+滚轮缩放。双击连线或选中后编辑，支持文本、判断/条件说明、颜色、透明度；判断只为说明，非可执行规则。边属性保存在本机kuat-edge-meta-v1，暂不含词条备份。


选择操作：空白拖动框选节点，拖动任一选中节点整体移动；Shift点击增减选择。Backspace仅从画布移除选中节点，编辑输入框或弹窗时不触发。单击边右侧显示边属性，节点右侧显示设定正文。滚轮继续用于画布移动。


拖动力学修正：流动时拖动不再暂停整个系统，只临时约束正在拖动的节点组；其他非固定节点持续响应连线拉力和排斥。按下即唤醒已休眠的模拟，松手解除临时约束，永久固定状态不变。


画布禁用浏览器文字选区和原生拖拽，避免干扰框选。双击节点打开大尺寸设定详情（正文、别名、标签、核对备注），支持进入编辑、关闭或Esc；详情正文仍可复制。弹窗期间暂停动画，关闭后按原布局状态继续。


设定正文编辑支持 Markdown 实时预览：左侧编辑、右侧即时排版，窄窗口上下排列；使用与设定详情相同的安全渲染器，保存仍由“保存词条”按钮触发。

## 登录态保存（2026-10-05）

新登录会话有效期为固定30天，启动时自动校验并载入云端。客户端使用Electron safeStorage（Windows系统用户加密）保存令牌、设备标识和到期时间至用户数据目录LoginSession.bin，不保存密码；创作数据仍只在云端。网络失败保留凭据并提供重试；到期或服务端撤销后重新登录。顶栏退出登录先保存待提交画布状态，再撤销当前会话并清除本机凭据；网络异常时提示重试。修改密码、停用或改级继续撤销相应会话。首次使用新版需登录一次，旧的内存会话无法恢复。


## 稳定启动入口

构建脚本默认输出到 `release/Current/`，并同步覆盖 `Latest/`。日常启动请使用 `Project-KUAT/Latest/KUAT.exe`；它的路径固定，每次更新构建后仍然有效。`release/Current/` 只保留当前构建，不再生成按日期散落的版本目录。
