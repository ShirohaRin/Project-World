知识综合与 AI 增强生物制造中的大语言模型

Large language model for knowledge synthesis and AI-enhanced biomanufacturing

作者：Wenyu Li、Zhitao Mao、Zhengyang Xiao、Xiaoping Liao、Mattheos Koffas、Yixin Chen、Hongwu Ma、Yinjie J. Tang
文献：Trends in Biotechnology，2025 年 8 月，第 43 卷第 8 期；开放获取；https://doi.org/10.1016/j.tibtech.2025.02.008

摘要

大语言模型（LLM）正在改变合成生物学（SynBio）的教育和研究。本综述涵盖 LLM 在生物制造中的进展与潜在影响。首先，我们总结近期发展，并比较美国和中国语言模型回答合成生物学基础问题的能力。其次，我们讨论 LLM 从非结构化数据提取合成生物学信息、构建知识图谱以及实现检索增强生成的应用。第三，我们预期 LLM 不仅将变革代谢建模和工程中的“设计—构建—测试—学习”（DBTL）循环，而且将在未来生物制造中实现自动驾驶实验室。最后，我们强调：需要建立 LLM 基准，促进可信赖的知识综合，制定防止滥用的生物安全框架，并鼓励人工智能科学家、合成生物学研究者和生物过程工程师之间的协作。

要点
• 对近期 LLM 在合成生物学研究中的可信赖性进行比较。
• 知识图谱促进文献数据检索与组织。
• LLM 使代谢模型获得新洞见和预测能力。
• LLM 自动化实验设计、决策和自动驾驶实验室。

面向未来生物技术的 LLM 快速增长

生物制造是利用工程化生物系统生产高价值化学品和药物。合成生物学与系统生物学的进步，使生物技术的指数级增长正在重塑生物制造格局。同时，大语言模型已成为一类突破性的生成式 AI，借助知识生成、总结、分类和复杂问题求解革新了研究[1]。近期突破显示，LLM 具有类人智能潜力，可辅助生物学研究和教育。已发布的 LLM 中，一些开源且便于定制，另一些则提供具有专有优化的开箱即用方案；它们在任务类型、模型架构、参数规模、可访问性和上下文长度方面各有不同（表 1 及补充信息文件 S1）。图 1 表明，美国和中国是 AI 研究的领先国家。当前工业界在大模型开发中发挥主要作用，而学术界产出多数生物学模型。

生物信息学数据的丰富加速了 LLM 在生物技术中的采用[2]。第一，遗传和蛋白质测序数据激增，数据集条目多达 70 亿，推动了蛋白质语言模型（pLM；见术语表）[3]。例如，拥有 70 亿参数的基因组基础模型 Evo 能以单核苷酸分辨率从基因组序列预测蛋白质功能，例如成簇规律间隔短回文重复序列（CRISPR）/CRISPR 相关蛋白（Cas）系统，并能学习 DNA 突变如何影响整体适合度[4]。第二，诸如 BioGPT 的 LLM 用于生物医学文献知识挖掘[5]。第三，语言模型如 LOWE（LLM 编排工作流引擎）支持药物发现和新化合物的生物合成。目前，LLM 与多种 AI 方法正协同演化，以解析生命规律并设计新的生物系统[6]。更广泛地说，NASA 和 IBM 正在构建跨越生物学、物理学、行星科学及天体物理学的基础模型 INDUS[7]。本综述聚焦 LLM 在生物制造中的应用，并前瞻其如何推动细胞工厂开发的 DBTL 循环新范式。

利用 LLM 检索生物技术数据

细胞工厂开发需要多层次工程来优化生物制造。研究者不仅要处理基因表达、酶工程和通路修饰，还需整体理解放大生物反应器条件下（如胁迫、代谢负担、遗传突变和氧限制）微生物的响应与调控[8]。训练 AI 模型必须具有可信、完整的知识数据库；可通过挖掘合成生物学（或代谢工程）出版物构建该库（截至 2024 年 10 月，PubMed 搜索结果逾 125 000 篇）。由于文献中没有结构化数据集[9]，LLM 可自动进行以往依赖劳动密集型人工输入的数据标注和检索[5]。预训练 LLM 能从合成生物学文献中蒸馏并选择特征，包括生物反应器条件、底物、产物、营养补充剂、生物合成通路步骤及合成生物学遗传元件等[10]；这些特征会影响生物制造性能的设计与预测。多种 LLM（如 Llama 2）已成功用于医学研究的特征识别[11,12]，也可用于从文本文件中提取生物制造信息[13]。此外，最新的 GPT-4o 和 o1 甚至可从图中提取发酵数据，便于校准生物过程模型参数[14]。

为提高 LLM 的可靠性、可解释性和推理能力，人们利用知识图谱将不同文献来源的合成生物学信息可视化和组织化[15]。语言模型自身还可在多模态知识图谱中寻找相似术语，从而扩展其综合异质数据集的效用[16]。人类知识持续微调 LLM 性能：量化低秩适配（QLoRA）[17]/低秩适配（LoRA）[18] 等技术通过选择性微调模型的一部分参数，显著助力训练。然而，小样本量有时会降低模型保留和有效运用通用知识的能力（即过拟合）。为应对这些挑战，提出了人类反馈强化学习（RLHF）[19]和检索增强生成（RAG）[20]。OpenAGI[21]、SELF-ALIGN[22] 等平台利用 RLHF，在保持研究完整性的同时，以最少人工监督增强任务求解能力；RAG 框架将检索器模型与外部文档和定制数据结合，从而改善信息检索[7]。

合成生物学问答中 LLM 可信赖性的比较

我们开发了问答系统 SynBioGPT，以来自文献的数据库测试开源 LLM 性能，数据库包含 51 777 篇摘要和 23 318 篇开放获取全文 PDF。训练使用一张 NVIDIA A40（40G），每个模型约占用 20G。我们采用 LangChain 切分内容、OpenSearch 建索引，并将切分片段嵌入为 knn_vector 以支持检索。用 100 个高质量问答对测试后，我们将片段大小优化为 300、Top N 为 8，微调 LLM 参数，并使用温度系数 0.01 的提示工程以保持输出一致。评估包含 79 个具体问题和 21 个开放问题，覆盖基因突变、产物查询和竞争通路探索（补充信息文件 S2）。在八个 LLM 中（图 2A），Llama3 准确度最佳。采用合成生物学论文摘要进行 RAG 后，所有 LLM 的准确度均从 25% 显著提高至 65% 以上；进一步以论文全文进行 RAG 后，阿里巴巴的 Qwen 显示出与 Llama3 相近的准确度（约 85%）。

基于我们近期的生成式 AI 研究[10]，图 2B 比较了 Qwen 和 OpenAI GPT-4 从 7 篇酵母发酵论文中检索数据的能力。总体而言，GPT-4 能获得比仅含 140 亿参数的 Qwen 更多的表格数据。当参数量增至 720 亿（即使用稍多计算资源）时，Qwen 获得的数据量大致与 GPT-4 相同。我们还采用面向摘要评估的召回率（ROUGE-L）和双语评估替补法（BLEU）（图 2C、D）两项 AI 评价指标。两种评价均显示，RAG 提升了 LLM 应对复杂问题的性能；ROUGE-L 明显优于 BLEU，表明 RAG 有效增强了 LLM 提取上下文相关信息的能力。然而，RAG 在提高检索数据精度方面仍有限制。

作为生物序列模型的 LLM

来自功能基因组学研究的测序数据（DNA/RNA/蛋白质）天然适合语言模型，因为其以字母为构件。近期，AI 与组学方法被整合以模拟分子和细胞的多样行为，为创建 AI 虚拟细胞（AIVC）带来突破性机遇[23]。具体而言，AIVC 的第一层将 DNA、RNA 和蛋白质建模为核苷酸或氨基酸的字符序列，形成分子层面的通用表征。与传统序列预测深度学习模型[24]相比，LLM 结构更统一，且不需要大量任务专用数据即可适配。这种适配性来自预训练和微调过程，使 LLM 能针对目标序列提取或生成提供多模态、端到端方案。基于 LLM 的序列模型包括 ProGen[25,26]、xTrimoPGLM[27]、ProGPT2[28] 和 ProLLaMA[29]，后者已展现优异的蛋白质性质预测和结构优化能力。值得注意的是，OpenCRISPR-1[30]用 CRISPR-Cas Atlas 微调基于 ProGen 的模型，以生成活性和特异性增强的多样 CRISPR-Cas 蛋白。Nvidia 的 BioNeMo 生物分子语言模型还结合 AlphaFold 等先进 AI 建模工具，精确预测逾 40 000 种人类蛋白质的结构[6]。

除 pLM 外，基因表达也是决定代谢调控和细胞功能的一种生物语言。近期研究建立了单细胞基础预训练模型：scFoundation 用于基因表达及药物反应预测[31]，scGPT 用于多组学数据分析[32]。此外，scMulan 使用多任务生成式预训练语言模型来解码单细胞转录组数据中的细胞功能[33]。当前序列语言模型仍缺少专为测序数据定制、能够有效捕获并解释其生物学意义的分词器。图神经网络与测序数据的整合（图序列模型）在推动从基因组到表型的预测方面潜力巨大[34,35]。

LLM 驱动的细胞工厂开发

细胞工厂开发需要酶工程、通路设计和发酵优化。由于代谢调控复杂，生物制造开发依赖 DBTL 循环，其中菌株开发同时受模型预测和实验测试指引。我们设想，经由 DBTL，LLM 与微生物细胞工厂的发展会相互受益（图 3）。LLM 可指引微生物细胞工厂开发：通过将文献和实验报告转化为文本并选择特征，LLM 加快机器学习工作流，以预测细胞在生物反应器条件下的性能。传统 ML 模型的特征往往不足以描述多层次生物学性质[36]；作为知识提取器，LLM 可识别和排序隐藏影响因素，使 ML 更可解释[37]。这些因素和相应特征评分可指引发酵优化并降低实验成本。LLM 还能为菌株工程提供有效策略。一项近期研究表明，LLM 可从逾 29 000 条记录（涵盖 1 210 种产物及 751 种生物）提取大规模代谢工程方法，从而增强 DBTL 循环[38]。另一项研究显示，带 RAG 的 Qwen 不仅能为解脂耶氏酵母通路工程提供遗传靶点和实验设计，还能提出新的生物合成通路假设[15]。

DBTL 循环需要可靠的代谢预测。但 LLM 的数学推理较弱，因而会在复杂工艺条件下预测代谢物产量等定量目标时失败[39]。因此，可将 LLM 与基因组尺度模型（GSM）[36,40]、技术经济分析（TEA）[41]等白盒模型整合，以扩展 LLM 推理并辅助生物制造商业决策。然而，机理模型作出简化假设，而 LLM 能弥合模型假设与现实条件之间的差距[42]。具体而言，可将基于蛋白质/RNA/DNA 的“语言”纳入多尺度组学数据和 GSM，以改善表型理解和生物学量化[43,44]。例如，从蛋白质序列和/或底物结构深度学习得到的酶周转速率知识，可促进工业 CHO 细胞系的代谢建模[45]。

LLM 与 AI 和组学数据的整合有望推动基因组尺度建模演化为全细胞建模，从而分析微生物细胞工厂中相互作用的遗传与代谢功能，并预测非线性动态响应[23]。这些常称为 AI 虚拟细胞的先进模拟，预计将革新计算机内细胞工程实验，并显著提高 DBTL 循环效率。

具有 LLM 智能体的自动驾驶实验室

尽管 DBTL 是当前细胞工厂开发策略，我们设想 LLM 将作为智能体，通过进一步减轻由硬件支持研究的劳动密集性而赋能生物制造。具体而言，“AI 科学家”是一种利用 LLM 协助人类科学家开展大规模分析和重复 DBTL 任务执行的新型智能系统[46]。这一工作流导致向自动驾驶实验室（SDL）的范式转变，包括意图（将合成生物学目标转换为计算工作流）、决策（决定实验方法）、执行（调度和监测工作流）和分析（将工作流输出实体化）[47]。LLM、机器人和人工监督的协同促进理性设计，最终实现生物铸造厂设计和发酵放大。

SDL 有以下优势。第一，LLM 通过将复杂任务分解为子推理步骤链来辅助任务规划[39]。例如，ChemCROW 利用思维链推理循环分解复杂任务，并识别与物理世界交互的相关工具[48]；分解蒸馏等方法[49]可将通路优化目标拆成酶选择、通路构建和通量分析，分别由特定工具解决。第二，LLM 自动化实验设计与规划。例如，蛋白质景观探索自动驾驶机器 SAMPLE[50]学习序列—功能关系来设计目标蛋白；简化分子线性输入系统（SMILES）把化学物结构转换为符号字符串，从而支持酶反应设计[51]。如 ChemCROW[48]和 Coscientist[52]所示，LLM 还可支持信息组织、子任务推理、复杂任务适宜工具的选择、实验方案准备和数据分析。近期，CRISPR-GPT 通过增加领域知识和外部工具来设计基因编辑实验[53]。第三，可将基于 LLM 的知识检索器与云计算和硬件控制整合，以更灵活、可扩展地实现实验室测试自动化[54]。例如，SynThreader 原为用自然语言处理检索实验方案而开发；将其与 LLM 整合可显著提高方案提取效率与准确性[55]。LLM 还可通过预测和监测实验约束与结果降低人工干预，例如在发酵过程中指引培养基制备、pH 调节和其他常规生物制造工作[56]。

与此同时，AI 进步促进更好的 SDL（图 3）。主动学习（AL）通过识别最有影响、应收集或验证的数据点来确定生物实验的优先级。近期成果显示，GPT-4 和 AL 利用簇边际选择优化无细胞蛋白质合成（CFPS），探索实验条件并提高抗菌蛋白产量[46,57]。此外，自我改进的 LLM 能审视自身推理以发现错误，从而为实验生成越来越精确的假设[58]。最后，数据安全始终是生物医学应用的重要关切。LLM 对齐确保模型既符合伦理/安全考量，也符合科学严谨性[59]。

AI—生物技术整合的生物安全

当前 AI—生物技术融合中的生物安全标准尚不充分。一方面，LLM 增加了生物武器或病原体合成的潜在风险[60]。以往，多项法规控制对危险和敏感知识的获取。若 LLM 可找到病原体和癌症的疗法[61]，它们也可能制造新的、更有害的病原体用于生物攻击[62]。例如，LLM 可提供关于天花病毒、工程化流感、炭疽杆菌和鼠疫耶尔森菌的信息；还可评估获取和传播生物制剂的可行性、时间、成本和后勤事项[63]。个人可能根据 LLM 的说明，采用反向遗传学等方法获取感染性病毒样本。即使指明有益意图，LLM 仍可能绕过安全措施，说明当前安全协议不足[64]。这是一场与时间赛跑：是实验室中将其付诸实现的个人先完成，还是建立工作程序的安全专家先完成。另一方面，迫切需要 LLM 监管，以确保数据隐私和知识产权机密性[65]。为避免信息泄露，必须使用安全的 LLM 应用程序接口；其他方法包括本地部署、隐私保护技术、零知识证明和联邦学习，以在训练和部署期间保护敏感信息[66]。此外，美国白宫近期 AI 行政命令[67]要求训练 AI 模型的开发者（尤其涉及合成生物学、计算操作超过 10²³ 次者）向联邦政府报告其网络安全、红队测试及其他安全措施。不过，为科学界利益，我们应负责任且建设性地利用技术进步，而非试图阻止其发展。

挑战与未来方向

LLM 尚未在生物制造行业广泛使用。我们预见以下挑战：生成式 AI 应用的一项关键障碍，是缺少能将不同生物信息学资源的多模态、非结构化数据无缝整合的管线[36,68]。合成生物学研究会产生多类知识，如图像（代谢通路图、分子结构[69–71]、细胞形态图像[72]等）和表格（质谱[73]、多组学表达数据[74]等）。特别是，文献挖掘中的图像到文本任务已在命名实体识别（NER）[75,76]和通路提取[77]等领域得到研究。但传统基于 DL 的图像提取方法常因化学术语不一致[77]、需要人工验证结果[10]等挑战而准确性不足。此外，从文献图形或曲线中提取时间序列数据仍有难度，因为当前 LLM 只能识别数据趋势[78,79]。因此，我们设想未来 LLM 可借助理解合成生物学术语、衔接不同图像格式、自动组织图像到数据以及标准化时间序列数据来解决这些挑战。

生物系统高度复杂且可重复性差。AI 方法可能受不完整知识库内容、信息偏差以及碎片化或干扰性信息影响。特别是，大部分合成生物学文献数据属于菌株工程、实验室培养和分子表征；但聚焦生物制造工艺放大或长世代生长中菌株稳定性的论文极少。因此，必须从中试研究和发酵行业（即技术成熟度等级 >3）收集数据，以确保 LLM 的质量和商业适用性。未来的合成生物学数据库构建和知识综合可受益于以下 LLM 方法：(i) 为调和冲突[80]并拒绝错误信息[81]，LLM 已显示出通过自主引导评估指令数据来过滤和标准化数据的巨大潜力[82]；(ii) LLM 可借助图网络连接和凸显合成生物学知识节点及来源[15]；(iii) 优化 LLM 长提示以确保有意义的表征[83]；(iv) LLM 接触多样化训练数据时表现更好[84]，因此学术界与产业界共享实验室和大规模发酵数据可微调 LLM 的适用性。这一微调过程包括整理高质量、多样化的实验室实验和工业规模操作数据集，随后进行领域专用预训练和任务专用监督学习[85]。模型借助领域专家反馈迭代改进的 AL 技术，还可进一步提升 LLM 可信赖性[57]。

如何测试 LLM 仍是开放问题，特别是在推理和事实核查相关任务上。多种基准[86–89]已经出现，用于从不同智能层次评价 LLM。但人为基准不足以评价机器智能，因为 LLM 有时会通过记住重复模式来“作弊”，从而不能识别逻辑不变的含义[39]，或因为它们在训练中见过泄露的元数据信息[84]。随着 LLM 持续演化，基准必须保持动态，才能有效衡量其性能。人们也已尝试通过探究 LLM 如何回答问题的机制[39]、测试其识别释义的能力[89]或使用基于熵的不确定性估计器[81]来应对这些挑战，这些方法或可克服 LLM 有时用以绕过常识性类人推理的统计技巧。

结语

当前合成生物学和生物制造的研究与教育正在受到 LLM 素养[90]和蛋白质语言模型[91]的重塑。面向生物制造的 LLM 需要大量计算成本、多模态数据资源、自动化设施、领域专家反馈和通行的安全监管规则（见“未解问题”）。学术界和产业界可在推进生物技术 LLM 方面互补；未来研究需要全球性、跨学科协作，推动新的计算进展，并通过良性循环促进科学学习和发现。

未解问题
• 如何设计 LLM，使其整合从分子相互作用到完整生物体的跨尺度生物知识？
• 面对海量组学数据，LLM 能否真正捕捉复杂代谢调控的精妙之处？
• 如何确保可解释 AI 的开发，以从黑箱模型导出可解释结果？
• 自动驾驶实验室最终能否取代传统 DBTL 循环？
