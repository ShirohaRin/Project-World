# IDEA 私有 Windows 客户端安装与接入

## 安装文件

当前 Windows x64 安装器位于：

```text
Project-IDEA/release/IDEA-Owner/IDEA-0.1.0-x64.exe
```

该安装器对应 Owner 私有版，应用名为 `IDEA`，不是普通的 `IDEA Assistant`。

## 主力机安装

1. 通过受控方式将安装器传到主力机。
2. 运行安装器，选择安装目录并完成安装。
3. 启动 `IDEA`。
4. 在设置中填入服务地址：`https://shiroha-rin.world`。
5. 使用已经关联 Owner 的邮箱完成验证码登录。

首次在新主力机登录时，服务器会登记一个新的 Owner Device。该设备在获得批准前仍会被服务端路由到 `idea_assistant`，不会获得私有 IDEA 身份或私人记忆。

## 设备批准

1. 在已批准的笔记本私有 IDEA 客户端登录同一 Owner 邮箱。
2. 打开设置中的跨设备记忆与私有设备面板。
3. 找到主力机的新设备记录，选择批准。
4. 返回主力机，退出并重新登录 IDEA。
5. 登录后界面应显示“私有服务已连接”，并可看到跨设备记忆和私有设备管理入口。

## 跨设备验收

1. 在笔记本私有 IDEA 客户端新建一段对话并发送消息。
2. 在主力机刷新会话列表，打开该会话。
3. 确认主力机能读取笔记本侧消息，并继续发送回复。
4. 回到笔记本刷新会话，确认主力机回复出现在同一会话。
5. 在任一私有客户端保存一条 Owner 记忆，确认另一台已批准设备能读取。

## 当前边界

- 私有客户端通过 `/api/assistant/chat` 接入云端 IDEA；服务端根据 Owner 账号关联和设备批准状态强制路由。
- 本地工作区的查看、编辑和运行仍在当前设备执行，不会自动同步或远程控制另一台设备。
- 主力机作为云端调度的本地执行节点，需要后续 Device Agent 完成后才具备远程任务、构建和 GPU 调度能力。
