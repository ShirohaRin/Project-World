## 架构阅读方式

| 区域         | 角色                       | 关键原则                   |
| ---------- | ------------------------ | ---------------------- |
| 数据、知识与实验输入 | 向模型提供机制、初始状态、参数范围和独立验证依据 | 训练、校准和盲测数据必须隔离         |
| 参数化与数据同化   | 把文献和实验观测转化为模型参数及其不确定性    | 参数缺失优先暴露为实验需求，不用任意假设填补 |
| 全局数学内核     | 提供整个细胞的一致状态、守恒约束和可解释动力学  | 是首期科研能力与批量预测的基础        |
| 标准模型接口     | 让不同精度的模块交换状态、通量、时间和置信度   | 禁止模块直接修改彼此内部状态         |
| 局部空间全模拟    | 只处理空间结构确实改变科研结论的过程       | 模块可升级，也必须可降级回分室近似      |
| 数据驱动代理层    | 处理高维组学、难测参数和大规模候选筛选      | 不能替代实验验证或破坏守恒、时间等机制约束  |
| 仿真平台与交互    | 组织运行、存档、回放，并提供三维探索界面     | 渲染与科学仿真解耦，动画不等于预测      |
| 验证与迭代闭环    | 用留出实验检验模型，并决定下一次投资方向     | 以预测增益和实验效率，而非画面或模型规模决策 |

## 空间化升级门

局部模块只有同时满足下列前提，才从全局数学内核升级为细胞器级空间全模拟：

1. 非空间模型已经在留出实验中达到可接受基线。
2. 残差有独立证据表明来自位置、几何、扩散、膜过程、运输或低拷贝随机性。
3. 已有可校准并保留部分盲测的定量空间数据。
4. 空间模型能回答分室模型无法回答的问题，或预计使关键预测误差降低至少 20%。
5. 已核算批量重复、参数搜索与存储的完整计算成本。
