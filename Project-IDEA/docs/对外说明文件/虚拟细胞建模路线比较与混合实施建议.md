# 虚拟细胞建模路线比较与混合实施建议

## 执行摘要

虚拟细胞不应简单理解为“把一个细胞在计算机里画出来”，而应理解为：在明确的细胞类型、培养或组织条件、干预方式、预测时间窗和可观测输出下，能够产生可被独立实验检验的预测模型。

两条思路分别是：

1. **数学模型路线**：用常微分方程、随机反应网络、代谢通量模型、偏微分方程等，描述细胞过程的动力学与约束。
2. **全模拟路线**：把细胞器、膜、囊泡运输、空间扩散、细胞骨架及局部反应等组织为可交互的多尺度仿真世界；视觉上可以接近游戏，但科学核心仍必须由可校准的动力学和物理模型支撑。

**两者可以并且应当同时存在，但不能从一开始等权建设。**近期最可行、性价比最高的方案是“数学模型为科学内核，按需引入空间化全模拟，并以交互可视化作为表现层”的混合路线。全模拟应当只进入那些已经被证明具有空间效应、局部随机性或细胞器结构效应的模块；不应为了视觉完整而模拟所有细节。

建议的最佳切换点是：当某个数学模块已经通过留出实验验证，且其预测误差的主要来源不再是参数或网络结构缺失，而是**分室、空间梯度、膜表面过程、运输或随机拷贝数效应**时，再把该模块升级为全模拟。这个切换点通常应发生在完成第一个可验证的、非空间化机制模型之后，而不是项目开始时。

## 术语与比较边界

| 术语 | 本文含义 | 不应混同的概念 |
| --- | --- | --- |
| 数学模型 | 以方程、约束、概率过程或统计模型表达机制与状态变化 | 只做静态通路图或相关性分析 |
| 全模拟 | 细胞器模块化、空间分辨、多尺度、随机或粒子化的计算仿真 | 仅有三维动画或游戏场景 |
| 科研能力上限 | 在限定任务分布内可被盲测实验支持的最大预测与解释能力 | “包含了所有部件”的宣传范围 |
| 原子级全细胞模拟 | 逐原子、跨完整细胞周期且包含真实化学反应的模拟 | 当前可执行的近期研发目标 |

本文中的“全模拟”主要指**任务导向的多尺度空间全细胞模拟**，而不是逐原子模拟一枚完整的人类细胞。后者在可预见的近期内没有可验证、可执行的工程路径。

## 路线一：传统数学模型

### 方法构成

数学模型不是单一技术，可按研究问题组合使用：

| 方法 | 适用问题 | 常见输出 |
| --- | --- | --- |
| 常微分方程（ODE） | 通路动力学、受体信号、代谢物浓度变化 | 时间轨迹、稳态、阈值、振荡 |
| 随机反应网络 / Gillespie 类方法 | 低拷贝分子、表达噪声、细胞间异质性 | 轨迹分布、状态转换概率 |
| 约束代谢模型 / FBA、dFBA | 代谢通量、培养基、基因敲除与生长 | 通量、增长率、代谢瓶颈 |
| 偏微分方程（PDE） | 扩散、浓度场、膜附近反应 | 空间梯度、波传播 |
| 统计或机器学习代理模型 | 高维观测、难直接测量的参数、快速近似 | 扰动响应排序、参数后验、预测区间 |

### 优点

| 优点 | 对科研的意义 |
| --- | --- |
| 可解释性强 | 每个状态变量、反应、参数和假设可以被审阅、替换和追溯 |
| 数据效率相对高 | 可把守恒、化学计量、已知网络和生物物理规律写入模型，减少纯数据拟合压力 |
| 易于反事实推演 | 可模拟基因敲除、剂量变化、营养限制、时间窗改变等干预 |
| 计算成本可控 | 多数通路或分室模型可在工作站运行，适合参数扫描与重复实验设计 |
| 验证边界清楚 | 可对预先声明的指标做留出条件、盲测扰动和灵敏度分析 |
| 便于逐步积累 | 单模块先成立，再通过明确接口耦合，不必一次覆盖全细胞 |

### 缺点

| 缺点 | 真实影响 |
| --- | --- |
| 参数缺失与不可辨识 | 不同参数组合可能产生相似输出，导致模型在未测条件下失真 |
| 手工建模成本高 | 梳理文献、确定反应、单位统一、校准、版本维护都需要长期投入 |
| 空间和结构表达不自然 | 若直接把所有细胞器、膜和运输过程写成方程，模型很快变得难以维护 |
| 跨尺度耦合困难 | 从毫秒级结合反应到数天级分化命运，需要不同层级的近似和接口 |
| 高维输出受限 | 要直接预测全转录组、蛋白组或成像表型，通常需要结合数据驱动模型 |

### 科研能力上限

在数据与实验闭环充分的前提下，数学模型的最高价值不是“重现全部细胞细节”，而是形成**可解释、可审计的因果预测器**。其可达到的上限可分三层理解：

| 上限层级   | 可达到能力                                 | 当前现实判断                   |
| ------ | ------------------------------------- | ------------------------ |
| 局部机制层  | 定量解释单一通路、代谢支路或细胞器功能；预测时间、剂量、阈值和反馈     | 成熟，可形成稳定科研产出             |
| 任务型系统层 | 对特定细胞、特定环境、有限扰动集合预测增殖、代谢、关键蛋白或细胞命运    | 可行，但必须通过持续实验校准           |
| 全细胞机制层 | 整合代谢、基因表达、复制、蛋白稳态等，解释较简单细菌或最小细胞的多过程耦合 | 已有先例；对真核和人类细胞仍只适合局部、受限任务 |

数学模型的硬上限来自**未知机制、缺失参数和观测不足**，并非仅来自求解器或服务器。若一个过程没有可测量的中间状态、没有合理的反应网络假设，增加方程数量只会提高自由度，不会自然提高预测力。

### 可行性、难度与成本

以下为 2026 年中国团队的**规划级总投入估算**，按人民币计价，包含研发人力、基础计算、必要的数据处理和合理的实验验证协作；不含新建大型湿实验平台、场地和重大仪器购置。已有数据、已有实验平台或高校共享算力可显著降低现金成本。

| 目标范围             | 周期与团队假设        |              总投入估算 | 可行性 | 技术难度 | 主要风险               |
| ---------------- | -------------- | -----------------: | --- | ---- | ------------------ |
| 单通路或单细胞器功能模型     | 6–18 个月，2–4 人  |   **150 万–800 万元** | 高   | 中    | 参数不足、实验读出不匹配       |
| 多模块机制模型          | 18–36 个月，4–8 人 | **800 万–3,000 万元** | 中高  | 高    | 模块接口、跨尺度耦合、维护成本    |

## 路线二：细胞器模块化的全模拟

### 方法构成

全模拟应采用多尺度表达，而不是把每个对象都用同一种精度处理：

| 层级 | 建议表达 | 例子 |
| --- | --- | --- |
| 全细胞状态 | 低维状态变量、质量守恒、事件调度 | 生长、细胞周期、能量状态 |
| 细胞器 | 分室模型、状态机、局部反应网络 | 线粒体、内质网、高尔基体、溶酶体 |
| 空间过程 | 反应扩散、格点、粗粒化粒子 | Ca²⁺ 波、囊泡运输、膜附近梯度 |
| 分子局部机制 | 随机反应或有限粒子模拟 | 低拷贝转录因子、受体聚集 |
| 呈现与交互 | 三维渲染、时间轴、状态热图、干预面板 | 可视化细胞器状态与模拟结果 |

这里“像游戏一样”的价值在于：提供可探索的三维交互界面、统一的状态观测和干预入口。**渲染帧率不等于科学时间步长，动画真实感也不等于预测准确性。**仿真内核应允许以分钟、秒或事件步推进，界面只消费经过验证的模型状态。

### 优点

| 优点         | 对科研的意义                            |
| ---------- | --------------------------------- |
| 自然表达空间结构   | 可研究细胞器定位、膜表面反应、局部扩散梯度和运输路径        |
| 适合研究涌现过程   | 多个局部规则可产生整体表型，便于观察反馈、拥挤和竞争        |
| 模块边界直观     | 线粒体、细胞核、膜、囊泡等可作为软件与科学模型的共同组织单元    |
| 便于跨学科沟通    | 生物、计算、成像和药物团队可在同一可视化状态空间讨论假设      |
| 可支持沉浸式实验设计 | 用户可以施加扰动、比较轨迹、定位预测不确定性，并反推需要测量的区域 |

### 缺点

| 缺点 | 真实影响 |
| --- | --- |
| 计算量增长非常快 | 空间网格、粒子数、随机重复和时间尺度一同扩大，成本可能呈超线性增长 |
| 参数量更多 | 除反应速率外还需位置、扩散系数、膜性质、运输速度、形态变化和初始结构 |
| 更难校准与验证 | 成像看到的形态、组学测到的分子量、模型内的局部状态并不天然一一对应 |
| 工程复杂度高 | 需要数值计算、并行调度、数据版本、可视化、交互、回放和可复现性体系 |
| 容易产生“视觉可信偏差” | 逼真的细胞器运动可能掩盖模型未经验证、参数随意设定的问题 |
| 难以覆盖全部尺度 | 同时精确描述分子结合、空间扩散、细胞周期和长期命运，当前不可执行 |

### 科研能力上限

全模拟的独特科研上限在于：对**空间组织是因果变量**的问题，给出数学模型中难以直观看到的机制预测，例如囊泡运输改变如何影响受体信号、细胞器邻近关系如何改变代谢与 Ca²⁺ 动态、拥挤如何改变反应可达性。

| 上限层级      | 可达到能力                           | 当前现实判断            |
| --------- | ------------------------------- | ----------------- |
| 空间化局部模块   | 解释某细胞器或膜区域的局部反应、扩散、运输与形态变化      | 可行，适合高质量成像和定量实验配合 |
| 空间化最小细胞   | 在粗粒化、多方法耦合下模拟部分细胞周期与涌现现象        | 已有重要先例，但计算和校准昂贵   |
| 任务型空间数字细胞 | 对固定细胞类型、环境与短时间窗，预测少数关键空间表型和功能输出 | 中长期可行，依赖数据与任务收窄   |
| 通用人类细胞全模拟 | 对任意状态、任意扰动、任意时间窗可靠预测完整人类细胞      | 当前不可行             |
| 原子级完整人类细胞 | 逐原子、真实化学、跨完整细胞周期、可验证地模拟         | 当前不应作为工程目标        |

因此，全模拟的上限不在于“画面更完整”，而在于针对空间性问题，构建比平均场或分室方程更有解释力的**局部因果实验场**。如果某研究问题的主要输出仅是增长率、代谢通量或少数蛋白浓度，加入三维细胞器模拟通常不会带来足以覆盖成本的科研增益。

### 可行性、难度与成本

| 目标范围 | 周期与团队假设 | 总投入估算 | 可行性 | 技术难度 | 主要风险 |
| --- | --- | ---: | --- | --- | --- |
| 单一空间化模块，例如线粒体网络或囊泡运输 | 12–24 个月，3–6 人 | **500 万–2,000 万元** | 中高 | 高 | 量化成像不足、参数与结构无法校准 |
| 3–5 个细胞器的受限空间仿真原型 | 2–4 年，6–12 人 | **2,000 万–8,000 万元** | 中 | 很高 | 模块耦合、GPU 成本、重复与回放系统 |
| 最小细胞的空间化、多尺度仿真 | 5–8 年，10–25 人 | **8,000 万–4 亿元** | 中低 | 极高 | 大量参数、跨学科协同、全生命周期验证 |
| 单一人类细胞类型的空间任务型数字孪生 | 6–12 年，25–60 人 | **3 亿–15 亿元** | 低 | 极高 | 空间多组学、长期状态、数据覆盖与外推 |
| 泛化人类全细胞或逐原子全细胞 | 未知 | **不建议给出可执行预算** | 当前不可行 | 不适用 | 计算、参数、初态与验证同时失控 |

**单次运行的公开现实标尺**：对 493 基因的最小细胞 JCVI-syn3A，已有空间分辨模型报告使用一块 NVIDIA Titan V 或 Tesla V100 模拟 20 分钟细胞时间约需 8–10 小时墙钟时间。单条轨迹的 GPU 租用费并不一定很高，但一个能够校准和发表的项目需要大量随机重复、参数搜索、失败重跑、数据存储和盲测，因此总成本的核心仍是人力、实验和数据整理，而不是一次 GPU 账单。

## 两条路线的直接比较

| 维度 | 数学模型路线 | 细胞器模块化全模拟路线 |
| --- | --- | --- |
| 首次可用原型 | 快，通常数月到一年半 | 慢，通常至少一年以上 |
| 主要科学优势 | 定量、因果、可解释、可进行反事实推演 | 空间结构、局部随机性、运输和涌现过程 |
| 主要成本中心 | 机制整理、参数校准、实验验证 | 成像/空间数据、并行计算、工程集成、实验验证 |
| 算力需求 | 低到中；局部模型通常可在工作站运行 | 中到极高；空间和随机重复会迅速放大 GPU/HPC 需求 |
| 参数需求 | 高 | 极高，额外需要空间、结构和运输参数 |
| 结果可解释性 | 强 | 取决于底层机制是否透明；视觉效果本身不构成解释 |
| 可视化与教学价值 | 中 | 高 |
| 适合的首期成果 | 可验证的通路、代谢、扰动预测模型 | 已验证数学内核的空间化演示和局部机制研究 |
| 最适合作为项目主线的阶段 | 第 0–2 阶段 | 第 2 阶段以后，按需引入 |

## 是否应当二者皆有

应当，但架构上要坚持“**内核与表现分离、局部高保真、全局低复杂度**”。推荐的关系如下：

```text
实验数据与公开知识
        ↓
参数估计、数据同化、不确定性量化
        ↓
全局数学内核：代谢、基因调控、能量、细胞周期、状态转换
        ↓
标准化状态与通量接口
        ├── 局部空间模块：膜、细胞器、扩散、运输、低拷贝随机过程
        └── 数据驱动代理：高维组学表征、难测参数近似、快速筛选
        ↓
可视化与交互层：三维细胞、轨迹回放、扰动比较、不确定性展示
        ↓
留出实验与盲测验证
```

### 混合路线的原则

1. **全局变量只保留真正需要的状态**：例如 ATP、NADH、关键代谢物、Ca²⁺、ROS、蛋白池、细胞周期与生长状态。
2. **模块通过明确接口耦合**：交换的是物质、能量、通量、时间事件与不确定性，而不是任意读写彼此内部变量。
3. **局部空间化必须有科学理由**：只有空间位置会改变结论时，才启用反应扩散、粒子或细胞器几何模型。
4. **每个模块都要能降级**：空间模块不可用或过慢时，应可退回到分室数学近似，保证批量筛选与可复现。
5. **界面明确区分事实、推断和动画**：测量数据、校准后的模拟结果、未校准的示意效果必须以不同状态呈现。

## 最佳切换点：从方程模型升级到全模拟的决策门

### 推荐结论

**最佳切换点不按日期、团队兴趣或画面需求决定，而按“误差来源已经空间化”决定。**

具体来说，当一个模块已完成非空间数学建模、可在留出实验中复现主要时间轨迹或稳态趋势，而其剩余失配集中表现为下列问题时，应将该模块升级为全模拟：

- 同样的总分子量或总通量，却因亚细胞位置不同产生不同表型；
- 均匀混合假设无法解释成像中的局部梯度、波、聚集、膜域或细胞器邻近关系；
- 囊泡、马达蛋白、细胞骨架或膜转运是研究假设中的必要因果环节；
- 关键分子处于低拷贝数，平均方程无法解释细胞间随机分化或事件触发；
- 分室模型的预测已对网格尺度、局部几何或扩散限制高度敏感；
- 有可用于校准和盲测的定量空间数据，例如活细胞成像、空间组学、FRAP、单粒子追踪或超分辨数据。

相反，如果误差仍主要来自未知速率常数、缺失调控边、实验批次效应、输入条件不明确或缺少独立验证数据，那么先做全模拟通常是错误的顺序；此时应优先补充实验、做参数可辨识性分析、缩小任务边界或改进数学内核。

### 可执行的四阶段路线

| 阶段 | 建设重点 | 进入下一阶段的门槛 | 是否引入全模拟 |
| --- | --- | --- | --- |
| 0：问题定义 | 确定一个细胞类型、一个研究场景、干预、时间窗、输出与盲测指标 | 明确至少一个可量化科研问题与可取得的数据 | 否 |
| 1：数学内核 MVP | 建立 1–3 个机制模块，完成参数范围、灵敏度和最小验证 | 在留出条件下优于基线；能指出最大不确定性来源 | 否，仅做概念级可视化 |
| 2：局部空间化验证 | 对一个已证明存在空间残差的模块建立反应扩散/粒子/运输模型 | 空间模块相对分室模型，在预注册指标上显著提高解释或预测能力 | 是，仅限该模块 |
| 3：混合数字细胞 | 用标准接口耦合全局数学内核、少数空间模块和高维数据代理 | 对未见扰动或未见条件完成独立盲测，并量化成本收益 | 是，按任务扩展 |

### 一个量化的切换判据

建议在立项时把下列条件设为“空间化投资门槛”。同时满足前四项，才批准把模块从数学模型升级为全模拟：

| 判据 | 建议门槛 |
| --- | --- |
| 基线成立 | 非空间模型已完成参数校准，并在留出实验上优于简单基线 |
| 残差归因 | 至少两类独立证据指向空间、运输、形态或随机效应，而非单纯参数缺失 |
| 数据可得性 | 已有或明确可获得定量空间数据，且数据可保留一部分用于盲测 |
| 科学增益 | 空间模型预期回答一个分室模型无法回答的明确问题，或使关键预测误差降低至少 20% |
| 计算预算 | 单次轨迹、重复次数、参数搜索和存储的预算已被测算，不以“实时画面”为验收目标 |
| 可维护性 | 模块具有输入、输出、版本、测试和降级策略，不与渲染逻辑强耦合 |

其中最关键的是：**空间模型必须带来可检验的增量价值。**若在留出空间数据或下游功能读出上，空间模型没有显著优于分室数学模型，就不应继续扩大细节。

## 推荐的首期项目边界

如果现在启动，建议不要以“通用虚拟细胞”作为首期交付，而将目标收窄为：

> 面向一种明确细胞类型，在一种明确应激或干预场景下，构建能预测 24–72 小时内关键代谢、信号、表达或表型变化的模块化数字细胞原型；对其中一个经验证的空间问题提供细胞器级全模拟。

可优先选择的研究场景包括：

| 场景 | 数学内核 | 适合空间化的局部模块 | 可验证输出 |
| --- | --- | --- | --- |
| 线粒体应激与 ROS | 能量代谢、氧化还原、凋亡阈值 | 线粒体网络、Ca²⁺ 局部耦合 | ATP、膜电位、ROS、细胞命运 |
| 自噬与溶酶体功能 | 物质流、蛋白稳态、营养感知 | 自噬体形成、囊泡运输与融合 | LC3、溶酶体负荷、存活率 |
| 受体信号与内吞 | 配体-受体动力学、下游通路 | 膜域、内吞、囊泡运输 | 磷酸化轨迹、受体定位、增殖 |
| 最小细菌或工程菌代谢 | 代谢通量、基因表达、生长 | 局部拥挤、扩散或分裂几何 | 增长率、代谢物、扰动表型 |

对资源有限的团队，首期建议预算为 **500 万–1,500 万元、18–24 个月、4–8 人**：约 60% 用于数据与实验验证协作，25% 用于建模、软件和数据工程人力，15% 用于计算与可视化原型。该预算对应的是“数学内核 + 一个局部空间模块”的原型，不对应完整人类细胞模拟。

## 核心风险与控制措施

| 风险 | 典型误区 | 控制措施 |
| --- | --- | --- |
| 目标失控 | 将“模拟细胞”定义成没有边界的万能任务 | 每个版本锁定细胞类型、条件、扰动、时间窗和输出 |
| 视觉压倒科学 | 先做漂亮三维动画，再补模型 | 渲染层只消费带版本与置信度的模型状态 |
| 参数不可辨识 | 用猜测参数填满模型，得到貌似合理的轨迹 | 先做灵敏度、可辨识性和不确定性分析；明确缺失实验 |
| 算力误判 | 把空间精度、随机重复和参数搜索只按单次运行估算 | 按完整研究工作流估算 GPU/CPU、存储和排队成本 |
| 验证不足 | 用训练数据或同一批次数据证明模型有效 | 保留未参与调参的扰动、批次、供体或成像实验作盲测 |
| 模块耦合失控 | 各团队直接访问彼此内部变量 | 定义状态、通量、单位、时间步和不确定性接口 |

## 最终建议

1. 把数学模型确定为虚拟细胞的第一性科研内核；它先提供可解释、可校准、可盲测的预测能力。
2. 把全模拟确定为按需增强层，而不是与数学模型平行竞争的替代路线。
3. 将首期“全模拟”限制在一个存在明确空间因果证据的细胞器过程，避免一开始搭建所有细胞器。
4. 使用“预测性能提升、减少实验搜索空间、可解释性、运行成本和盲测成功率”评价项目，而不是使用模型规模、分子数量或画面完整度评价项目。
5. 若项目需兼顾科研展示、教学或产品交互，可尽早做三维界面；但界面与科学仿真必须解耦，未校准内容只能标为示意。

从科研投入产出看，最优路径不是“方程模型以后再做游戏”，而是：**先用数学模型获得可信的细胞状态与预测，再让空间全模拟只承担它真正不可替代的部分。**
