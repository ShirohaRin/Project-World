# 云端知识库与长期记忆路线图

## 决策状态

一期受控服务端长期记忆已实施；云端知识库与语义检索仍纳入后续规划。

一期使用受控 IDEA 服务端的 `platform.db` 存储显式确认的长期记忆，并复用账户、空间、Owner 路由、审计和同步事件边界。会话、任务和长期记忆不进入 GitHub；桌面端仅可通过受限 API 读取跨设备状态。

当前实现不自动从聊天沉淀记忆。读取必须由请求显式传入 `use_memory=true`，并且仅注入当前账户、空间与可访问命名空间内最多五条匹配记录。删除采用软删除，审计只保存动作与范围，不保存记忆正文。

## 重新评审触发条件

同时满足以下条件后，重新提出并评审本路线图：

1. 离线桌面客户端完成当前确认范围的开发、构建和使用验证。
2. 用户明确启动服务端与基础 Agent 的开发阶段。
3. 已确定云端部署位置、账户与认证方式，以及数据保留和删除策略。

## 目标架构

云端能力应拆分为权限独立的 MCP，而不是向 IDEA 授予单一全能服务：

| MCP | 默认权限 | 用途 |
|---|---|---|
| `knowledge-search` | 只读 | 按项目隔离检索文档、架构决策和已批准资料。 |
| `memory-read` | 只读 | 读取用户明确授权保存的长期偏好、目标和协作约定。 |
| `memory-write` | 受控写入 | 仅在展示拟写入内容、目标空间和作用范围，并获得用户明确确认后写入。 |

会话上下文默认不自动沉淀为长期记忆。项目知识库必须按项目、用户或组织边界隔离，IDEA 仅在当前任务已明确授权的范围内读取。

## 实施前决策清单

- 确认云端服务提供方、数据存储地域、成本与可用性要求。
- 设计身份认证、MCP Token 轮换、HTTPS、审计日志与最小权限策略。
- 定义长期记忆的数据模型、写入确认交互、修订历史、删除与导出机制。
- 定义项目知识库的租户隔离、来源元数据、索引更新和检索评估方案。
- 规定离线降级行为：云端 MCP 不可用时，IDEA 仍可完成本地协调，并明确提示跨设备记忆不可用。
- 为读写权限、跨项目隔离、误写入回滚和离线降级补充自动化测试。

## 非目标

- 不在当前离线客户端阶段连接任何云端 MCP。
- 不在本路线图触发前部署 Linux 服务或导入现有本地记忆。
- 不将飞书接入、后台任务或其他第三方业务集成纳入本阶段。
