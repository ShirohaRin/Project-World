# Program IDEA 内部立项企划书

## 执行摘要

Program IDEA 面向生物科技研发中的知识密集型工作，拟建设以文献调研与综述为首期能力的科研智能体平台。项目将公开论文与经授权资料组织为可检索、可追溯的知识底座，由 Agent 协助研究人员完成主题检索、论文解读、证据比较、综述提纲和草案撰写。首期不以训练基础大模型为目标，而通过检索增强生成、专业工作流和人工审核验证真实科研任务的价值；在数据、算力、评估集和导师支持具备后，再决定领域微调或模型训练方案。建议以 9 个月完成 MVP 和小范围试点。

## 需求与机会

科研人员通常需要从大量异构文献中确认研究问题、方法、结果和局限，再把材料组织为开题报告、研究计划或综述。通用 AI 可以提供初步文本支持，但若缺少受控资料、引用回链和专家审核，结果难以直接用于科研讨论。

项目的切入机会在于：文献调研与综述拥有清晰的输入、可审阅的输出和相对成熟的评价方式，适合先建立可信工作流。通过真实课题试点，团队能够积累领域任务集、资料处理规范、评价标准和用户反馈，为后续更复杂的实验辅助、数据分析及模型训练提供基础。

## 项目方案

平台由三部分组成：本地优先的工作界面负责文档与任务交互；知识服务负责文献接入、检索、权限过滤和引用回链；科研 Agents 负责将研究问题拆解为检索、阅读、比较和写作任务。每一份生成材料均保留文献来源、版本与人工修订记录。

| 一期能力 | 使用方式 | 主要产出 |
| --- | --- | --- |
| 文献调研 | 输入研究问题、关键词和范围，系统检索并归类证据 | 研究脉络、重点文献、争议点与待核验问题 |
| 论文解读 | 解析研究问题、方法、结果、局限与可复现性 | 结构化论文卡片与方法摘要 |
| 主题综述 | 基于经确认的资料组织提纲和草案 | 可编辑综述初稿、引用清单与证据映射 |
| 审核与沉淀 | 研究人员审阅、修改和归档结果 | 项目级知识资产与版本记录 |

项目的差异在于将“生成文本”置于可核对的知识流程中：系统不只输出结论，还需要展示结论所依据的资料；不确定或证据不足的内容以待核验状态保留；科研人员始终拥有最终判断权。

## 大模型训练路径

模型训练是长期研究方向，不应在一期直接承担交付压力。基础大模型训练需要大量高质量数据、稳定算力、系统化评测与持续运维，且难以在缺少具体任务基线时判断投入产出。

一期结束后，若试点证明 RAG 与 Agent 工作流具有明确价值，并已获得合规授权的领域数据和评估集，可按以下顺序评估：提示与工具策略优化、检索模型或重排序模型优化、参数高效微调、私有化推理部署。是否开展更大规模训练，取决于导师立项支持、算力预算、数据权属及测评结果。

## 路线与成果

| 阶段 | 时间 | 阶段成果 |
| --- | --- | --- |
| 立项与试点定义 | 第 1 月 | 明确试点课题、资料边界、评价标准和资源条件 |
| 文献知识底座 | 第 2 至 3 月 | 可处理授权资料的解析、索引、检索与引用服务 |
| 调研与综述原型 | 第 4 至 5 月 | 可完成主题调研、论文解读和综述草案的 Agent 原型 |

| MVP 交付 | 第 8 至 9 月 | 小范围可用的系统、说明材料和后续训练决策依据 |

## 团队与支持需求

项目由 SRH 负责总体推进。项目需要导师或课题组提供科研方向审阅、试点任务和资料使用边界；工程侧需要具备检索系统、Agent 编排、桌面端或 Web 交互能力的协作者；试点阶段需要研究人员参与结果评审。

建议内部评审优先确认四项支持：导师立项认可、一个明确的试点课题、可合法使用的文献或内部资料范围、基础算力与开发协作条件。预算和大模型训练投入在一期效果评估后另行确定。

## 风险控制

科研内容的可靠性依赖于来源质量、检索能力和人工审核。系统应禁止将无来源内容包装为确定性结论，并对权限受限资料执行访问控制。对于实验、临床或生物安全相关问题，平台仅提供资料整理与研究辅助，不替代专业判断、实验验证和既有审批流程。

## 立项请求

请求批准 Program IDEA 以“生物科技文献调研与综述 Agent”为一期工程启动，周期暂定 9 个月；批准以导师指导的试点课题验证成果，并在一期评估后审议领域微调或模型训练的资源投入方案。
