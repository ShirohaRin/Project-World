## 5.3.1 分阶段使用建议

1. **基础算法回归**：继续使用固定的 WDBC；它体量小、标签清晰，适合 PCA、PCoA、层次聚类和 k-means 的确定性/真实数据测试。
2. **表达矩阵方法**：从 GEO 或 GTEx 选择一个明确 accession，固定处理后的表达矩阵和样本元数据，用于 PCA、聚类和批次诊断。
3. **微生物组方法**：从 HMP、Qiita 或 MG-RAST 选择一个公开 study，保留 feature table、metadata；后续加入 Jaccard、UniFrac 后再做完整 PCoA 对照。
4. **多组学与复杂流程**：TCGA/GDC、ENCODE、PRIDE 和 1000 Genomes 放在输入层、质量控制和元数据契约更稳定之后使用。

## 5.3.2 数据登记规范

每次将具体数据集用于测试时，至少登记：`repository`、`accession/study ID`、`数据版本或 release`、`下载日期`、`许可/访问条件`、`样本数`、`特征数`、`矩阵方向`、`距离度量或预处理`、`元数据字段`、`预期验证结论`。原始大文件不直接纳入代码仓库；可提交小型固定快照或生成脚本，但必须保留来源和校验信息。

复现取数的命令：

```powershell
Invoke-WebRequest -Uri 'https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=nuccore&id=NC_001422.1&rettype=gbwithparts&retmode=text' -OutFile 'tests/data/phiX174_NC_001422.1.gbk'
```

> 本快照供参考读取（`common/reference_io/`）的真实数据用例使用。后续做比对与变异检测时，
> 还需要**配套的 reads**（同一 accession 对应的 SRA 测序数据）才能做端到端验证，
> 那部分要按同一规范单独登记。
