# 阅读—归纳—修正—进化

## 目标

把一次阅读变成可复用、可修正、不过度膨胀的长期学习结果。学习主题可以动态变化：

- **文风**：叙述节奏、句式、视角、对白、动作与心理描写、标点习惯、段落组织。
- **知识**：事实、概念、人物关系、世界观、流程、规则、因果和不确定性。
- **其他主题**：只有用户明确指定时才建立新的主题。

## 触发条件

用户要求“读一章学习”“归纳文风”“总结知识”“修正文风记忆”“根据新材料进化”“整理已有学习记忆”时调用。

## 固定循环

```text
确定主题与材料
→ 阅读原文或可靠材料
→ 提炼可观察事实
→ 区分事实、推断和待确认项
→ 对每条候选结论计算正确概率与置信度
→ 仅压缩已确认且高度重复的内容
→ 对照已有记忆，用新材料复核、修正或保留存疑项
→ 只保存经复核的长期结论
→ 记录本轮变化与下次观察点
```

## 阶段 1：确定范围

1. 明确本轮材料、目标主题和用途。
2. 文风学习优先读取用户指定章节的最终 Markdown；不要把 OCR 中间产物当作长期知识。
3. 知识学习优先使用用户指定的原文或项目知识库；不凭印象补全。
4. 若主题不明，分开询问“学习文风”还是“学习知识”，不要混成一份记忆。

## 阶段 2：阅读与提炼

### 文风观察维度

只记录材料中能举例验证的现象：

- 叙事视角和信息释放顺序。
- 段落长短与场景切换节奏。
- 动作、环境、心理、对白的比例和衔接。
- 句式长短、连接词、重复结构和语气词。
- 对话中的人物差异、停顿、打断和潜台词。
- 形容词、比喻、拟态词、标点及省略号的使用。
- 轻松、紧张、冷峻等情绪如何通过具体动作和语言表现。

### 知识观察维度

- 明确事实及其出处或材料位置。
- 实体、人物、地点、时间和关系。
- 规则、状态、因果、限制和例外。
- 材料明确说了什么，未说明什么。
- 与已有知识冲突的地方及冲突证据。

禁止把“读起来像”“应该是”直接写成稳定记忆。

## 阶段 3：归纳与压缩

每轮最多产生少量核心结论，优先保存能指导未来工作的规则，而不是保存整章摘要。

每条结论应包含：

```text
主题：文风 / 知识 / 其他
结论：一句可执行或可核验的表述
依据：材料中的现象或事实，以及相反证据
正确概率：0%～100%，表示当前结论为真的估计
置信度：高 / 中 / 低，表示证据数量、质量与独立性是否足够
适用范围：本作品、本项目或更广范围
状态：已确认 / 暂定 / 存疑 / 已否定
```

### 概率与置信度计算

这是基于证据的显式估计，不假装是精确统计学结果：

1. 先设定与现有证据相符的先验概率；没有基础时使用 50%。
2. 为每条独立证据评估支持或反驳力度：直接原文、可重复观察、独立材料的权重高；单句印象、转述或同源重复的权重低。
3. 新证据与旧证据同源、只是换一种说法时，不重复累计。
4. 综合支持和反驳证据后给出正确概率，并说明概率变化原因。
5. 置信度不等于概率：高概率但证据单薄仍只能是低/中置信度；多份独立可靠材料支持且缺乏反证，才是高置信度。

推荐门槛：

- **已确认**：正确概率 ≥ 90%，且置信度高；可以压缩并写入稳定长期规则。
- **暂定**：正确概率 70%～89%，或置信度中；保留为带条件的倾向，继续观察。
- **存疑**：正确概率 40%～69%，或证据相互冲突；不压缩为结论，保留证据与下一轮验证点。
- **已否定**：正确概率 < 40%，或有可靠反证；不作为有效规则，可保留简短的修正理由以避免重复错误。

只有语义、证据链和适用范围都相同，且每一条均为“已确认”的记忆，才可以思考后压缩合并。对于只适用于单章的细节：留在章节笔记，不写入长期记忆。对于相互冲突的结论：保留冲突、概率和证据，不能强行平均。

## 阶段 4：修正与复核

1. 先检索已有相关记忆，并读取其证据、概率、置信度与适用范围。
2. 将新观察与旧结论逐条对照；按新增独立证据更新正确概率和置信度，再决定确认、细化、修正、降级、否定或继续存疑。
3. 修正文风时，不把模仿总结写成僵硬模板；总结“倾向”和“边界”，不规定每句话必须如此。
4. 修正知识时，保留来源、时间、不确定性和反证。
5. 只有被当前材料支持、正确概率与置信度达到对应门槛、且对未来有复用价值的结论，才写入云端长期记忆。
6. 压缩不是默认动作：先思考各条是否确实同义、同证据链、同适用范围；只合并高度重复的已确认结论。

## 阶段 5：学习模型的数学建模与数据留存

长期学习不仅输出结论，也要留下可研究的建模数据；但不能伪造观测值、把主观感觉当统计事实，或在样本过少时宣称模型有效。

### 最小数据单元

每轮学习为一条观测 `t`，每个候选结论为一个假设 `h`。记录：

```text
observation_id：材料与轮次的稳定标识
主题：文风 / 知识 / 其他
hypothesis_id：结论的稳定标识
材料范围：章节、段落、来源或时间范围
支持证据数 s：去重后的独立支持证据数量
反驳证据数 r：去重后的独立反驳证据数量
证据权重：每条证据的来源质量、直接性与独立性
先验概率 p0：更新前的正确概率
后验概率 p1：吸收本轮证据后的正确概率
置信度：高 / 中 / 低
状态：已确认 / 暂定 / 存疑 / 已否定
动作：新增 / 确认 / 修正 / 降级 / 否定 / 合并
原因：概率或状态变化的可追溯说明
```

### 概率模型

默认采用可解释的贝叶斯赔率更新，而非伪精确的黑箱分数：

```text
prior_odds = p0 / (1 - p0)
posterior_odds = prior_odds × Π LR_i
p1 = posterior_odds / (1 + posterior_odds)
```

其中 `LR_i` 为第 `i` 条**独立**证据的似然比。直接原文、多轮可复现观察、相互独立材料可以提高 `LR_i`；反证使用小于 1 的 `LR_i`。同源证据只能合并为一次更新，不能重复相乘。

若无法合理量化似然比，必须写明“定性更新”，保留支持/反驳理由和概率区间，不能伪装成精确计算结果。

### 研究数据原则

1. 原始材料、提取特征、假设、证据、概率更新和最终判断必须可区分、可追溯。
2. 文风研究可记录可复算特征，例如段落长度分布、对白比例、句长、标点频率、动作/环境/心理描写标注比例；标注标准必须随数据保留。
3. 知识研究可记录事实三元组、来源、时间、冲突关系和证据更新序列。
4. 数据不足时报告样本量、缺失值、标注偏差和适用边界；不得从一章文本外推到全书。
5. 长期统计、导出格式、模型参数或实验设计由用户提出研究需求后再建立，避免预设研究口径污染数据。

## 阶段 6：写入记忆

使用 IDEA Owner 私域记忆保存长期结论。记忆应按主题分组，推荐分类：

- `style-learning`
- `knowledge-learning`
- `learning-meta`

不得把整章正文、整篇 OCR、临时排错过程或未经复核的猜测写入记忆。

每次写入前先评估已有内容：只有高度重复、同义且均为已确认的结论才压缩。若记忆过于繁杂，先按证据、正确概率、置信度、状态和适用范围做审计，再形成“当前有效总规则”；存疑项、冲突项和低置信度项必须保留其证据与验证条件，不能为了简洁而删除。

## 本项目当前文风学习基线

从《来自深渊的我今天也要拯救人类》第78章观察到的、仅用于后续复核的初步倾向：

- 叙事以第三人称推进，环境和动作承担转场与情绪铺垫。
- 通过短段落、对白和停顿制造镜头感；关键场面常在平静叙述后突然收紧。
- 人物性格主要通过动作失控、语气差异、沉默和对话中的权力关系显现，而不是长篇解释。
- 安吉尔段落以酒、邋遢动作、戏谑语气形成轻佻外表，同时用简短而危险的命令露出压迫感。
- 艾尔娜段落减少情绪词，以站姿、停顿、寡淡短句和命令表现冷静与威势。
- 轻松对白和危险信息并置，形成反差；省略号、重复词和断续句用于表现迟疑、醉态或等待。

以上是待后续章节复核的倾向，不是不可改变的仿写模板。

## 输出格式

向用户汇报时简洁说明：

1. 本轮阅读材料与主题。
2. 新确认的少量规则，以及其正确概率、置信度和证据摘要。
3. 哪些旧记忆被合并、修正、降级或保留存疑。
4. 本轮新增的可追溯观测数据；若没有建立定量数据，明确说明原因。
5. 下一轮需要观察的点。

不虚构“已经学会”无法由材料支持的风格，也不报告未实际写入的记忆。
