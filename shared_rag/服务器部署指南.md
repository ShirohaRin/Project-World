## 1. 上传文件到服务器

你需要把 `d:\shared_rag\server\` 文件夹传到服务器上。

### 方式 A：SCP 上传（推荐）

```powershell
# 在你 Windows 开发机上执行（PowerShell）
# 替换 user 和 IP 为你的实际信息

scp -r D:\shared_rag\server user@你的服务器IP:/opt/
```

### 方式 B：宝塔面板上传

1. 登录宝塔面板 → 文件管理
2. 进入 `/opt/` 目录
3. 新建文件夹 `server`
4. 进入 `server` 文件夹，上传以下文件：
   - `rag_api_server.py`
   - `Dockerfile`
   - `requirements.txt`
   - `docker-compose.yml`
   - `.env.template`

## 2. 一键部署

SSH 登录服务器后，执行以下命令：

```bash
# 1. 进入目录
cd /opt/server

# 2. 创建文档存放目录
mkdir -p knowledge_private knowledge_public

# 3. 复制环境变量模板
cp .env.template .env

# 4. 编辑 .env，填入你的 API Key（见第3步）
nano .env

# 5. 构建并启动（首次运行约 5-10 分钟，需下载依赖和嵌入模型）
docker compose up -d --build

# 6. 查看启动日志
docker compose logs -f
# 看到 "共享 RAG 知识库服务 v2.0 启动中..." 即成功
# 按 Ctrl+C 退出日志
```

### 国内服务器加速

编辑 `Dockerfile`，把 pip install 那行改成用清华源：

```dockerfile
# 原来的：
RUN pip install --no-cache-dir -r requirements.txt

# 改成：
RUN pip install --no-cache-dir -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 3. 生成 API Key

在服务器上生成三个安全的随机 Key：

```bash
python3 -c "import secrets; print('ADMIN_KEY:  ', secrets.token_hex(24))"
python3 -c "import secrets; print('LANGBOT_KEY:', secrets.token_hex(24))"
python3 -c "import secrets; print('INGEST_KEY: ', secrets.token_hex(24))"
```

把输出的三行填进 `.env` 文件：

```env
RAG_ADMIN_KEY=生成的48位字符串
RAG_LANGBOT_KEY=生成的第二个48位字符串
RAG_INGEST_KEY=生成的第三个48位字符串
```

**重要**：把这三个 Key 记下来！后续 TRAE 和 LangBot 配置都要用。

## 4. 首次上传文档

### 宝塔面板上传（最简单）

1. 宝塔面板 → 文件管理
2. 进入 `/opt/server/knowledge_public/` 或 `/opt/server/knowledge_private/`
3. 上传你的 PDF/MD/TXT/DOCX 文件

### SCP 上传

```bash
# 从你的电脑传文档到服务器
scp 你的文档.pdf user@服务器IP:/opt/server/knowledge_public/
```

### 上传后重建索引

```bash
cd /opt/server
curl -X POST "http://localhost:8080/api/admin/rebuild?collection=all" \
     -H "X-API-Key: 你的ADMIN_KEY"
```

## 5. 验证服务是否正常

```bash
# A. 健康检查（不需要 Key）
curl http://localhost:8080/api/health
# 输出：{"status":"ok","timestamp":"..."}

# B. 查看统计
curl http://localhost:8080/api/stats -H "X-API-Key: 你的ADMIN_KEY"

# C. 测试检索公开库
curl -X POST http://localhost:8080/api/search \
     -H "X-API-Key: 你的LANGBOT_KEY" \
     -H "Content-Type: application/json" \
     -d '{"query":"测试","top_k":3}'

# D. 测试私有库（ADMIN 专属）
curl -X POST "http://localhost:8080/api/search?collection=private" \
     -H "X-API-Key: 你的ADMIN_KEY" \
     -H "Content-Type: application/json" \
     -d '{"query":"测试","top_k":3}'

# E. 验证 LangBot Key 不能访问私有库（应返回 403）
curl -X POST "http://localhost:8080/api/search?collection=private" \
     -H "X-API-Key: 你的LANGBOT_KEY" \
     -H "Content-Type: application/json" \
     -d '{"query":"测试","top_k":3}'
```

E 返回 403 是正常的！说明私有库确实被保护了。

## 6. 配置 TRAE 连接

### 步骤 1：先测试连通性

在 Windows PowerShell 中：

```powershell
$env:RAG_SERVER_URL="http://你的服务器IP:8080"
$env:RAG_ADMIN_KEY="你的ADMIN_KEY"
python D:\shared_rag\trae\test_connection.py
```

全部 ✅ 才能继续。

### 步骤 2：在 TRAE 中添加 MCP

TRAE → 设置 → MCP → 添加 → stdio 类型：

| 配置项 | 值 |
|--------|-----|
| 名称 | `rag-knowledge-base` |
| 命令 | `python` |
| 参数 | `D:\shared_rag\trae\rag_mcp_proxy.py` |
| 环境变量 | `RAG_SERVER_URL=http://你的服务器IP:8080` |
| 环境变量 | `RAG_ADMIN_KEY=你的ADMIN_KEY` |

保存后重启 TRAE，确认 MCP 面板中显示绿色连接。

### 步骤 3：在 TRAE 中测试

对 TRAE 说："查一下知识库的状态"

## 7. 配置 LangBot（飞书）连接

### 步骤 1：复制插件

```bash
# 在服务器上
cp /opt/server/../shared_rag/langbot/rag_plugin.py /你的langbot路径/plugins/
```

或者从本地 SCP 上传：

```bash
scp D:\shared_rag\langbot\rag_plugin.py user@服务器IP:/opt/langbot/plugins/
```

### 步骤 2：配置插件

LangBot Web 面板 → 插件管理 → 启用 `rag_knowledge` 插件：

```yaml
rag_server_url: "http://localhost:8080"
rag_api_key: "你的LANGBOT_KEY"     # 注意是 LANGBOT_KEY
rag_top_k: 5
rag_auto_trigger: true
```

### 步骤 3：飞书测试

在飞书中对机器人发：`/rag 查询内容`

## 8. 日常运维

```bash
cd /opt/server

# 查看状态
docker compose ps

# 查看日志
docker compose logs --tail=50

# 重启
docker compose restart

# 加文档后重建索引
curl -X POST "http://localhost:8080/api/admin/rebuild?collection=all" \
     -H "X-API-Key: 你的ADMIN_KEY"

# 列出所有文档
curl http://localhost:8080/api/documents -H "X-API-Key: 你的ADMIN_KEY"

# 删除文档
curl -X DELETE "http://localhost:8080/api/documents/public/文件名.pdf" \
     -H "X-API-Key: 你的ADMIN_KEY"
```

### 调整分块参数

编辑 `.env` 文件：

```bash
nano /opt/server/.env

# 修改：
RAG_CHUNK_SIZE=800         # 增大 = 每块更长
RAG_CHUNK_OVERLAP=100      # 增大 = 相邻块重叠更多

# 重启
docker compose restart

# 重建索引
curl -X POST "http://localhost:8080/api/admin/rebuild?collection=all" \
     -H "X-API-Key: 你的ADMIN_KEY"
```

## 9. 故障排查

| 问题 | 检查 |
|------|------|
| 容器起不来 | `docker compose logs --tail=100` 看错误 |
| 端口冲突 | 改 `docker-compose.yml` 端口映射，如 `8081:8080` |
| 内存不足 | 换更小模型：`RAG_EMBEDDING_MODEL=all-MiniLM-L6-v2` |
| 检索结果为空 | 确认 `knowledge_public/` 里有文件 → 重建索引 |
| TRAE 连不上 | 宝塔面板 → 安全 → 放行 8080 端口 |
| 403 权限错误 | 检查用的是 ADMIN_KEY 还是 LANGBOT_KEY |

### 宝塔面板反向代理（可选）

1. 宝塔 → 网站 → 添加站点 → 域名填 `rag.你的域名.com`
2. 设置 → 反向代理 → 目标 URL: `http://localhost:8080`
3. 一键申请 SSL → 获得 `https://rag.你的域名.com`

之后 TRAE 中把 `SERVER_URL` 改为 `https://rag.你的域名.com`。
