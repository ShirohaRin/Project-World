# Project World · 主项目内容

这里保存 Project World 主项目的世界观、正文与设计资料。主项目的目标是创造、构建、模拟、完善完整的架空世界，并将其映射到现实世界；全部子项目都服务于这一目标。

目录沿用 `IDEA` 这一名称，但它不是 [Project IDEA 软件平台](../Project-IDEA/README.md)。整个项目体系见[仓库总览](../README.md)。

## 内容入口

| 位置 | 内容 |

| [WORLD.md](WORLD.md) | 世界设定资料；阅读和使用时遵循文内的叙事层级与披露限制 |

## 与各子项目的关系

- Project IDEA 提供开发与科研工作能力；主项目侧保留 IDEA 的角色映射与生活助手需求。
- Project K.U.A.T 将承接世界观关系、设定卡片、逻辑连接、思维导图和多 Agent 世界模拟等管理与创作能力。
- Project World 网站承担网页介绍与功能入口；站点展示内容需要从主项目资料中明确选择。
- Shiroha 网站服务于白羽奈绪的个人表达。

## 内容边界与当前状态

本目录已有实际设定和正文资料；完整世界模拟仍是长期目标，不能因资料存在就视为已经实现。K.U.A.T 的新定位也不表示这里的资料已经迁移或结构化。

世界内叙事、作者设计和未公开设定应保持区分。文内明确限制披露的内容，不应自动复制到网站、公开介绍或其他叙事层级。本 README 只说明资料组织，不展开这些设定。

项目关系依据白羽奈绪于 2026-10-03 的说明整理。
