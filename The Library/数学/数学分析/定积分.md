起源：为解决历史遗留问题而建立的运算方法，问题为如何计算一个曲边梯形的面积，解决方法为分割，近似求和，取极限。
定义：设闭区间$[a,b]$上有$n - 1$个点，依次为
	$a = x_0 < x_1 < x_2 < ... < x_{n-1} < x_n < b$
则对于每个$\Delta_i=[x_{i-1},x_i],i=1,2,3,...,n$ 为$[a,b]$的一个分割，记为$T=\{\Delta_1,\Delta_2,\Delta_3,...\}$
















$$\lim_{a\rightarrow1}(\int_{0}^{1-a}{\frac{1}{(1-x)^2}dx}+\int_{1+a}^{2}{\frac{1}{(1-x)^2}dx})=\lim_{a\rightarrow1}[\frac{1}{a}-1+(-1-\frac{1}{a})]$$
