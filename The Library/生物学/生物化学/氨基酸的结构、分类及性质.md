# 氨基酸的结构、分类及性质

> 本笔记依据《绪论2026》整理。课件文字已融入统一笔记结构；补充说明以“补充”标记。

## 氨基酸的基本结构

分子中含有氨基和羧基的化合物叫氨基酸。氨基酸可以看成是羧酸碳链上的氢原子被氨基取代后的产物。

氨基酸按碳架一般可分为脂肪族氨基酸和芳香族氨基酸。根据氨基和羧基的相对位置，可分为α-氨基酸、β-氨基酸、γ-氨基酸……。由蛋白质水解得到的天然氨基酸都是α-氨基酸。

L-α-氨基酸的基本骨架可表示为：

```text
        H
        |
H3N+ — C — COO−
        |
        R
```

其中，R代表侧链。甘氨酸的R为H，丙氨酸的R为CH₃。

> **补充：** α-氨基酸的α-碳同时连接氨基、羧基、氢原子和R基。R基的大小、形状、极性、酸碱性和反应活性，决定了氨基酸在蛋白质折叠、催化和分子识别中的性质。

## 氨基酸的命名与立体化学

### 命名

系统命名法：以羧酸为母体，氨基为取代基来命名。例如：2-氨基戊二酸。

俗名：天然氨基酸（α-氨基酸）常根据其来源或性质称呼。

### 手性与旋光性

天然氨基酸除氨基乙酸（甘氨酸）外，α-C都是手性C，都具有旋光性，其构型一般采用D/L标记法。

氨基酸的构型由α-C（离羧基最近的C*）决定。

天然氨基酸的三个特点：

1. 都是α-氨基酸，具有两性电解性质；
2. 除甘氨酸外，都具有手性；
3. 都是L-型。

氨基酸的构型和旋光性是两个不同的概念：

[^1]- 构型：D-型，L-型。
- 旋光性：左旋（−），右旋（+）。

> **补充：** 甘氨酸的α-碳连接两个相同的氢原子，因此没有手性中心。D/L是相对于甘油醛参照体系的构型标记；左旋/右旋则是实验上观察到的平面偏振光旋转方向，二者不能相互直接推出。核糖体合成的标准蛋白质氨基酸通常为L型，但天然存在的氨基酸范围更宽，某些生物体中也可发现D型氨基酸或非标准氨基酸。

## 20种标准蛋白质氨基酸

根据R基团的结构或性质特点巧记20种氨基酸口诀：

| 记忆分组   | 氨基酸       | 记忆提示                      |
| ------ | --------- | ------------------------- |
| 脂肪链    | 甘、丙、缬、亮、异 | 脂肪链R基团的5种                 |
| 羟基与硫   | 丝、苏、半、蛋   | 含-OH，-S者共4种               |
| 酸碱基团   | 天、谷、精、赖、组 | 酸性碱性者5种                   |
| 杂环与芳香环 | 脯、酪、苯、色   | 芳香环和杂环R基团者4种              |
| 酰胺     | 门冬酰胺、谷酰胺  | 两种酰胺                      |
| 共同特征   | —         | 都有密码属“常见”（常见氨基酸都有特异的遗传密码） |

20种标准蛋白质氨基酸由遗传密码编码，并在翻译过程中被核糖体按mRNA信息装配进多肽链。三字母缩写和单字母缩写是表示蛋白质序列的常用方式。

## 按R基化学结构分类

### 芳香族氨基酸

指R基团含有芳香环，有苯丙氨酸、酪氨酸和色氨酸3种：苯丙氨酸（Phe，F）、酪氨酸（Tyr，Y）、色氨酸（Trp，W）。

### 杂环氨基酸

指R基团含有咪唑基，只有1种，即组氨酸（His，H）。

### 杂环亚氨基酸

指R基团取代了α-氨基的一个氢而形成一个杂环，只有1种，即脯氨酸（Pro，P）。

### 脂肪族氨基酸

除上述氨基酸外，其余15种均为脂肪族氨基酸：

- 甘氨酸（Gly，G）
- 丙氨酸（Ala，A）
- 缬氨酸（Val，V）
- 亮氨酸（Leu，L）
- 异亮氨酸（Ile，I）
- 甲硫氨酸（Met，M）
- 赖氨酸（Lys，K）
- 精氨酸（Arg，R）
- 天冬氨酸（Asp，D）
- 谷氨酸（Glu，E）
- 丝氨酸（Ser，S）
- 天冬酰胺（Asn，N）
- 苏氨酸（Thr，T）
- 半胱氨酸（Cys，C）
- 谷胺酰胺（Gln，Q）

> **补充：** 教材对“脂肪族”的边界有时采用宽泛分类，因此分类结果可能随教材体系略有不同。色氨酸和酪氨酸通常按芳香族单列，脯氨酸按杂环亚氨基酸单列。

## 按可解离基团分类

- **碱性氨基酸：**指氨基酸分子中含二个氨基（及以上）和一个羧基。有精氨酸、赖氨酸和组氨酸3种。
- **酸性氨基酸：**指氨基酸分子中含有一个氨基和两个羧基。有谷氨酸和天冬氨酸2种。
- **中性氨基酸：**指氨基酸分子中含一个氨基和一个羧基。有15种，包括天门冬酰胺和谷胺酰胺。

## 按R基极性分类

- **非极性氨基酸：**指R基团含有脂肪烃链或芳香环等，有丙氨酸、缬氨酸、亮氨酸、异亮氨酸、苯丙氨酸、色氨酸、甲硫氨酸、脯氨酸。
- **极性不带电的氨基酸：**指R基团含有不解离的极性基团，能与水形成氢键。包括甘氨酸、丝氨酸、苏氨酸、酪氨酸、天冬酰胺、谷氨酰胺、半胱氨酸。
- **极性带负电荷的氨基酸：**指R基含有可解离的极性基团，在pH6—7时带净负电荷。有天门冬氨酸和谷氨酸2种。
- **极性带正电荷的氨基酸：**指R基团含有可解离的极性基团，在pH7时带净正电荷。有赖氨酸、精氨酸和组氨酸3种。

> **补充：** “极性不带电”是特定pH范围和分类体系下的简化说法。酪氨酸、半胱氨酸和组氨酸的侧链在特定pH条件下可以发生解离或质子化，因此精确计算蛋白质净电荷时要结合各基团的pKa。

## 按人体营养需求分类

### 必需氨基酸

必需氨基酸（essential amino acid）是指人体（或其它脊椎动物）不能合成或合成速度远不适应机体的需要，必需由食物蛋白供给的氨基酸。包括赖氨酸、苯丙氨酸、缬氨酸、蛋氨酸、色氨酸、亮氨酸、异亮氨酸和苏氨酸八种。

精氨酸和组氨酸人体虽能够合成，但合成的量通常不能满足正常的需要，被称为半必需氨基酸。

### 非必需氨基酸

非必需氨基酸（nonessential amino acid）是指人（或其它脊椎动物）自己能由简单的前体合成，不需要从食物中获得的氨基酸。20种基本氨基酸中除必需氨基酸和半必需氨基酸外均属此类。

> **补充：** “非必需”不等于“没有营养价值”，而是指在特定生理条件下机体通常能够合成。婴幼儿、生长发育期、疾病、创伤或严重应激时，某些氨基酸的需要量可能增加，可称为条件必需氨基酸。

## 不常见蛋白质氨基酸

有些氨基酸虽然不常见但在某些蛋白质中存在，它们是在已合成的肽链上由基本氨基酸经专一酶催化的化学修饰转化而来的：

- 5-羟赖氨酸：植物细胞壁蛋白、纤维胶原蛋白。
- 4-羟脯氨酸：连接组织的纤维胶原蛋白。
- 3-甲基组氨酸。
- γ-羧基谷氨酸：血栓凝血蛋白酶原和结合钙离子的蛋白质。
- 焦谷氨酸。
- 锁链赖氨酸：弹性纤维蛋白。
- 6-N-甲基赖氨酸：肌肉中的收缩蛋白质（肌球蛋白）。

> **补充：** 这些氨基酸通常属于翻译后修饰产物。羟脯氨酸有助于胶原蛋白稳定；γ-羧基谷氨酸能够结合Ca²⁺，参与凝血相关蛋白与膜表面的定位；赖氨酸残基的交联有助于弹性纤维形成。

## 非蛋白质氨基酸

非蛋白质氨基酸包括β-丙氨酸、γ-氨基丁酸、高半胱氨酸、鸟氨酸（ornithine）和瓜氨酸（citrulline）。

鸟氨酸和瓜氨酸是精氨酸合成和尿素循环的关键中间产物。

> **补充：** 非蛋白质氨基酸不直接作为核糖体合成蛋白质的标准单体，但可作为代谢中间体、神经递质或特殊生理功能分子。γ-氨基丁酸是重要抑制性神经递质，鸟氨酸和瓜氨酸参与含氮废物的转运与排出。

## 氨基酸的物理性质

- 小分子物质，分子量都没有超过1000。
- 为无色晶体，熔点高。
- 各种氨基酸其味道随不同氨基酸有所不同。
- 都能溶于强酸和强碱溶液中。
- 除胱氨酸、酪氨酸外，均溶于水。
- 除脯氨酸和羟脯氨酸外，均难溶于乙醇和乙醚。

> **补充：** 氨基酸熔点较高、在水中常以离子或两性离子形式存在。溶解度受到pH、温度、离子强度和侧链性质影响；在等电点附近，净电荷接近零，某些氨基酸或蛋白质的溶解度会降低。

## 两性解离与等电点

氨基酸的两性解离

在不同pH条件下，两性离子的状态也随之发生变化。

氨基酸在一般情况下不是以游离的羧基或氨基存在的，发生两性电离，在固态或水溶液中形成盐。

K值定义为该基团失去一个质子（H⁺）的平衡常数。

在某一pH的溶液中，氨基酸解离成阳离子和阴离子的趋势及程度相等，成为兼性离子，呈电中性。此时溶液的pH值称为该氨基酸的等电点。

- pH < pI：阳离子。
- pH = pI：氨基酸的兼性离子。
- pH > pI：阴离子。

以甘氨酸为例，主要形式可表示为：

```text
甘氨酸盐（A+） ⇌ 等电点甘氨酸（A±） ⇌ 甘氨酸盐（A−）
```

> **补充：** 两性离子同时含有带正电的铵基和带负电的羧酸根，但分子总电荷为零。pI是平均净电荷为零的pH，不表示所有分子都只有一种形式，也不等于溶液中不存在带电分子。

## pI的计算

K′₁和K′₂表示解离常数：

```text
K′1 = [A±][H+] / [A+]
K′2 = [A−][H+] / [A±]
```

pI时，[A+] = [A−]。

```text
[H+]² = K′1 K′2
lg[H+] = (lg K′1 + lg K′2) / 2
pH = (pK′1 + pK′2) / 2
pI = (pK′1 + pK′2) / 2
```

对于中性氨基酸：

```text
pI = 1/2(pK1 + pK2)
```

对于酸性氨基酸：

```text
pI = 1/2(pK1 + pKR)
```

对于碱性氨基酸：

```text
pI = 1/2(pK2 + pKR)
```

氨基酸的pI值等于该氨基酸的两性离子状态两侧的基团pK值之和的二分之一。

> **补充：** 公式的关键不是机械记忆“取哪两个pKa”，而是先按pH升高顺序排列各基团的解离过程，再找出包围净电荷为零形态的两个pKa。酸性氨基酸的中性形态位于两个羧基解离之间；碱性氨基酸的中性形态位于两个氨基解离之间。

## 甘氨酸滴定曲线的理解

甘氨酸的滴定过程可概括为：低pH下以A⁺为主；随着pH升高，羧基先失去质子形成两性离子A±；继续升高pH，铵基失去质子形成A⁻。滴定曲线中的缓冲区对应可解离基团的pKa附近，等电点位于两性离子占优势的区间中心附近。

## 课后习题

### 手性

组成蛋白质的20种常见氨基酸中，甘氨酸不具有旋光性。其结构基础是甘氨酸的α-碳连接两个相同的氢原子，不是手性中心，因此不存在一对互为镜像且不可重合的对映体。

### 氨基酸分类与表示

分子量最小的是甘氨酸，化学式NH₂CH₂COOH，三字母缩写Gly，单字母缩写G。

分子量最大的是色氨酸，化学式C₁₁H₁₂N₂O₂，三字母缩写Trp，单字母缩写W。

酸性氨基酸是天冬氨酸（Asp，D）和谷氨酸（Glu，E），其侧链含有额外羧基，在生理pH附近可失去质子而带负电荷。

碱性氨基酸是赖氨酸（Lys，K）、精氨酸（Arg，R）和组氨酸（His，H），其侧链含有可质子化的含氮基团，在一定pH范围内可带正电荷。

结构中带有苯环的氨基酸是苯丙氨酸，化学式C₉H₁₁NO₂，Phe，F；酪氨酸，化学式C₉H₁₁NO₃，Tyr，Y。色氨酸含有稠合的吲哚环，而不是单独的苯环；若按“含芳香环”理解，还应列入色氨酸，化学式C₁₁H₁₂N₂O₂，Trp，W。

> 注：不同教材对“带有苯环”和“芳香族”的表述范围可能不同。严格按结构判断时，苯丙氨酸和酪氨酸含苯环，色氨酸含吲哚芳香杂环。

### 罕见氨基酸X的pI和质子化状态

已知一种罕见氨基酸X，其结构类似于赖氨酸，但侧链氨基的pKa值发生了改变。它的三个可解离基团的pKa值如下：

- pKa₁（α-羧基）= 2.20
- pKa₂（α-氨基）= 9.31
- pKa₃（侧链氨基）= 8.95

X是类似赖氨酸的碱性氨基酸。升高pH时，α-羧基先解离，随后pKa较小的侧链氨基解离，最后α-氨基解离。净电荷变化为：

```text
低pH：+2
失去α-羧基质子后：+1
失去侧链氨基质子后：0
失去α-氨基质子后：−1
```

因此，包围净电荷为零形态的是pKa₃和pKa₂：

```text
pI = 1/2(pKa2 + pKa3)
   = 1/2(9.31 + 8.95)
   = 9.13
```

**答案：pI=9.13。**

在pH=8.50时，pH低于pKa₃=8.95和pKa₂=9.31，但高于α-羧基的pKa₁=2.20。α-羧基基本已经解离为−1；两个氨基仍以质子化形式为主，因此主要形态的净电荷为+1。

**答案：主要带+1电荷。**

在pH=10.00的碱性溶液中，若逐步降低pH或进行反向滴定，最先接受质子的基团是pKa较大的α-氨基（pKa₂=9.31），而不是侧链氨基（pKa₃=8.95）。原因是pKa越大，基团的共轭酸越弱、未质子化形式越倾向于接受质子；在反向滴定中，pKa较大的基团先被质子化。

**答案：α-氨基最先接受质子。**

> “被滴定”需要说明方向：若从低pH升高，是逐步失去质子；若从pH=10.00降低pH，则是逐步接受质子。这里按题目“接受质子”的表述，采用反向滴定解释。

## 重点回顾

- 天然蛋白质氨基酸通常是L-α-氨基酸；甘氨酸没有手性中心。
- D/L构型与左旋/右旋是两个不同概念。
- R基决定氨基酸的结构类别、极性、酸碱性和部分生物学性质。
- 酸性氨基酸含额外羧基，碱性氨基酸含可质子化的侧链含氮基团。
- 不常见蛋白质氨基酸多由翻译后修饰产生；非蛋白质氨基酸常参与代谢或信号过程。
- pI计算必须先确定净电荷为零形态，再选其两侧的pKa。
- pH低于pI时氨基酸总体偏正，pH高于pI时总体偏负。

[^1]: 对于常见的α-氨基酸，可以采用Fischer投影式判断。将结构按照下面的方式摆放：
	
	text
	
	```text
	      COOH
	        |
	H — C — NH2
	        |
	        R
	```
	
	此时氨基位于左侧，是**L型氨基酸**。
	
	如果氨基位于右侧：
	
	text
	
	```text
	      COOH
	        |
	NH2 — C — H
	        |
	        R
	```
	
	则是**D型氨基酸**。
	
	因此，在标准Fischer投影式中：
	
	|类型|α-氨基的位置|
	|---|---|
	|L型|左侧|
	|D型|右侧|
	
	但这个判断方法必须建立在投影式摆放规范正确的前提下，不能把任意角度画出的结构式直接套用。
