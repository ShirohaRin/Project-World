## 一、先建立判断力：这条路线的天花板与陷阱

> 这几篇决定你「**不该做什么**」。先读它们，能省掉大量弯路。

- [ ] **Protap：蛋白质建模真实下游任务基准**（arXiv 2506.02052）
  - https://arxiv.org/html/2506.02052v1
  - **必读理由**：给出三条直接否定常见误判的实证结论
    - 大规模预训练编码器**常常不如**在下游小数据集上监督训练的编码器
    - **下游微调时引入结构信息，可匹敌甚至超过大规模序列语料预训练的 PLM** ← **本项目核心命题的实证支撑**
    - 领域特定的生物学先验能提升专门任务表现

- [ ] **VenusX：蛋白质细粒度功能理解基准**（arXiv 2505.11812）
  - https://arxiv.org/abs/2505.11812 ｜ https://arxiv.org/html/2505.11812v1
  - **读什么**：序列-结构模型 vs 纯序列模型的对比协议与结果
  - **要点**：序列-结构模型在未见家族上泛化更好；SaProt-650M 在全部 InterPro Cross 分割上最好或次好；域级分类比 ProtBert 高 5.6% AUPR

- [ ] **层选择与模型规模收益的量化**（arXiv 2512.00376）
  - https://arxiv.org/html/2512.00376v1
  - **要点 1（规模）**：ESM-2 从 650M 升到 3B/15B，下游任务平均仅提升 **3–5%**，代价是 **5 倍显存**（3B 约 40GB、15B 约 80GB）与 **10–50 倍**处理时间
  - **要点 2（层选择）**：中后段层（20–33）在无监督聚类上比最后一层高 **32%**；对监督分类也有提升
  - **实操价值**：直接决定你用哪个规模的模型、从哪层取特征

- [ ] **蛋白质语言模型的计算最优性**（arXiv 2406.07249）
  - https://arxiv.org/html/2406.07249v1
  - **读什么**：pLM 的规模-收益曲线
  - **要点**：pLM 存在性能平台期；35M 模型单遍数据的困惑度可接近 ESM-2 15B

## 二、基座模型选型

> 决定用哪个模型做表征。要读懂架构差异与能力边界，而不只是看排行榜。

- [ ] **ESM-2 官方文档与模型卡**
  - BioNeMo Recipes：https://docs.nvidia.com/bionemo-recipes/2.5/models/ESM-2/
  - BioNeMo Framework：https://docs.nvidia.com/bionemo-framework/latest/models/ESM-2/
  - 模型卡 650M：https://huggingface.co/facebook/esm2_t33_650M_UR50D
  - 模型卡 3B：https://huggingface.co/facebook/esm2_t36_3B_UR50D
  - **要点**：BERT 式双向编码器；650M = 33 层 / 20 头 / hidden 1280；3B = 36 层 / 40 头 / hidden 2560；**最大输入 1022 残基**（超长需截断）；LoRA 比全参微调省 2.5–4 倍显存

- [ ] **SaProt：结构感知词表**（ICLR 2024，西湖大学）
  - 论文：https://openreview.net/forum?id=6MRm3G4NiU
  - 代码：https://github.com/westlake-repl/SaProt
  - 中文报道：https://hub.baai.ac.cn/view/44697
  - **读什么**：3Di token 如何构造、词表如何合并、"结构感知"到底带来了什么增量
  - **要点**：Foldseek 把 3D 结构转成 1D 离散 token，与氨基酸 token 做笛卡尔积构造词表；4000 万条序列-结构对训练；650M；10 项下游任务全面超越基线

- [ ] **ESM Cambrian / ESM C**
  - https://pypi.org/project/esm/3.1.0/
  - **要点**：300M 媲美 ESM-2 650M；**600M 媲美 3B 并接近 15B**；许可分 open 与 non-commercial 两档

- [ ] **ESM-3：多模态生成模型**
  - 官方博客：https://www.evolutionaryscale.ai/blog/esm3-release
  - **要点**：最大 98B（闭源，仅 API/云）；开源 `esm3-open-small` 为 **1.4B，非商用许可**

- [ ] **ProstT5：序列与结构的双语语言模型**（NAR 2024）
  - https://academic.oup.com/nargab/article/6/4/lqae150/7901286
  - **读什么**：另一种把结构引入语言模型的思路，与 SaProt 对比着看

- [ ] **融合结构知识的蛋白质预训练模型进展**（物理学报 2024，中文综述）
  - https://www.cpsjournals.cn/article/doi/10.7498/aps.73.20240811
  - **读什么**：入门综述。把结构融合的几条技术路线串起来，含各模型的**算力需求对照表**

## 三、方法路线

> 具体用什么架构把「结构」映射到「功能」。

- [ ] **PARSE：局部结构嵌入 + 知识统计**（PNAS 2025）
  - https://www.pnas.org/doi/10.1073/pnas.2513219122
  - **读什么**：不训练模型也能做功能注释的思路
  - **要点**：酶催化功能预测 **F1 > 85%**；给出**残基层注释**；**无需监督训练**，可对罕见功能做 one-shot 预测；已用于注释 AlphaFold 数据库的「暗蛋白质组」

- [ ] **PANDA-3D：基于 AlphaFold 结构的功能预测**（NAR G&B 2024）
  - https://pmc.ncbi.nlm.nih.gov/articles/PMC11302463/
  - **读什么**：GVP-GNN + Transformer decoder 的完整实现
  - **要点**：**直接证明了用预测结构做功能预测是可行的**；训练 51,245 / 验证 6,419 / 测试 4,719（0.95 相似度截断）

- [ ] **MSNGO：3D 结构 + 网络传播**（Bioinformatics 2025）
  - https://doi.org/10.1093/bioinformatics/btaf285 ｜ https://pmc.ncbi.nlm.nih.gov/articles/pmid/40327458/
  - **读什么**：结构特征与 PPI 网络传播的融合方式

- [ ] **GO 功能预测的图表示学习综述**（PeerJ 2024）
  - https://pmc.ncbi.nlm.nih.gov/articles/PMC11569786/
  - **读什么**：DeepFRI / Struct2GO / GearNet 等方法族全景，含各自的数据类型与局限

- [ ] **蛋白质功能预测的编码策略综述**（Frontiers 2025）
  - https://www.frontiersin.org/journals/bioengineering-and-biotechnology/articles/10.3389/fbioe.2025.1506508/full
  - **读什么**：各 PLM 在功能预测上的编码方式对比，含 CAFA3 / CAFA4 / Human2024 结果

- [ ] **ProtFun：GAT + 蛋白语言模型**（Bioinformatics Advances 2025）
  - https://pmc.ncbi.nlm.nih.gov/articles/PMC12132266/
  - 代码：https://github.com/bozdaglab/ProtFun

- [ ] **SaMCL：结构感知 PLM 的多任务协同学习**（Briefings in Bioinformatics 2026）
  - https://academic.oup.com/bib/article/27/2/bbag178/8658877
  - **读什么**：多任务协同的框架设计，可参考其任务组织方式

## 四、数据与基准

> 开工前必须摸清：标签有多少、结构从哪来、数据集怎么划分。

- [ ] **UniProtKB 统计（2026_03 发布）**
  - https://www.uniprot.org/uniprotkb/statistics
  - **要点**：总计 150,006,383 条；**人工审阅（Swiss-Prot）仅 575,748 条**；其中「蛋白质水平证据」仅 121,477 条
  - **含义：这是本项目标签的天花板，不是结构数量**

- [ ] **UniProt 预计算 embedding（可直接下载，省下大量算力）**
  - 说明页：https://www.uniprot.org/help/embeddings
  - 下载目录：https://ftp.uniprot.org/pub/databases/uniprot/current_release/knowledgebase/embeddings/
  - **要点**：使用 `prottrans_t5_xl_u50`；提供 **per-protein（1024 维）** 与 **per-residue（L × 1024）** 两种粒度；`.h5` 格式；覆盖 Swiss-Prot 与人类等参考蛋白质组；随每次发布更新

- [ ] **AlphaFold DB 主站 / FAQ / 下载页**
  - https://alphafold.ebi.ac.uk/ ｜ https://alphafold.ebi.ac.uk/faq ｜ https://alphafold.ebi.ac.uk/download
  - **要点**：262,739,159 个预测模型；46 个完整蛋白质组可整包下载；**CC-BY-4.0（学术与商用均可）**

- [ ] **AlphaFold DB 全库体量与取用策略（23 TiB）**
  - NVIDIA 说明：https://intellabs.github.io/Open-Omics-Acceleration-Framework/applications/alphafold/alphafold_master/afdb/
  - 官方论文：https://pmc.ncbi.nlm.nih.gov/articles/PMC10767828/
  - **要点**：全库约 **23 TiB、3 × 2.14 亿个文件**；官方明确建议「只下载与具体用例相关的子集」

- [ ] **AlphaFold DB 复合物数据集（2026-05 新增）**
  - https://www.ebi.ac.uk/about/news/updates-from-data-resources/alphafold-database-community-datasets/
  - **要点**：新增约 3100 万复合物预测，含约 220 万同源二聚体 + 7.9 万异源二聚体高置信条目

- [ ] **ProteinGym（变体效应基准）**
  - https://proteingym.org/
  - **要点**：217 个 DMS 测定、超过 250 万个取代突变

- [ ] **Foldseek 的 PDB100 库**
  - https://wwwuser.gwdg.de/~compbiol/data/hhsuite/databases/hhsuite_dbs/pdb100_foldseek_230517.tar.gz
  - **要点**：约 **19GB**；做结构检索与生成 3Di token（SaProt 路线）都要用

- [ ] **数据集划分：同源性感知分割**（重点，别跳过）
  - 参考 VenusX 与 PANDA-3D 的分割协议：0.95 / 0.8 / 0.7 相似度截断、InterPro Cross 分割
  - **必须掌握**：不做这一步，测试集会混入训练集的同源蛋白，指标全部虚高

- [ ] **结构功能预测数据集规模参考**
  - PANDA-3D（训练 51,245）：https://pmc.ncbi.nlm.nih.gov/articles/PMC11302463/
  - 序列-结构特征融合（PDBset 训练 29,893）：https://academic.oup.com/bioinformatics/article/41/7/btaf374/8174967
  - ProtFun（DeepGOZero 约 5.9 万 / NetGO 约 6.2 万 / DeepGraphGO 11.7 万）：https://pmc.ncbi.nlm.nih.gov/articles/PMC12132266/
  - **要点**：主流数据集规模在 **3 万–12 万蛋白**量级——这决定了算力需求远低于语言模型

## 五、工程与算力

> 动手部署时再查，不必现在精读。

- [ ] **ESM-2 微调显存参考**
