
# 一，有效数字
--------------------------
	**1，有效数字及其位数。**
		测定的数据 = 确定的数字 + 一位不确定数字
		例如：20.00mL准确表示20.0毫升，最后一位为可疑数字，且
		20.00mL = 0.02000L ≠ 0.02L。
	**2，有效数字的确定。**
		有效数字最后一位是不确定数字，倒数第二位反映出一起的最小刻度单位。
		数字0是否是有效数字取决于它的位置，只有在末端的0是有效数字，非末端的0是定位数字，不起到有效数字的作用。
		电子天平称重时去小数点后四位，移液管，滴定管读体积时以mL为单位，取小数点后两位。
		浓度取四位有效数字，分子量取四位有效数字。
		误差和偏差一般取一位有效数字，最多取两位。
			pH其1-2位有效数字，注意，对于pH值，只有小数部分被视为有效数字，整数部分仅起到定位作用。
		与测量无关的纯数，不受有效数字束缚。
		当计量单位由大变小时，采用科学计数法，不能改变有效数字位数，
		化学秉衡计算中，结果一般为两位有效数字。
		确定有效数字位数时采用四舍六入五成双的原则
		修约数字为5时，如果5后面有数字，则一律进位。
		修约有效数字时只允许一次修约。
	3，运算规则。
		加减运算，结果所保留的位数，取决于绝对误差最大的数。（小数点后位数最少），“先取齐后加减。”
		乘除运算，结果所保留的位数取决于相对误差最大的数（有效数字位数最少）。“先取齐后乘除。”
