# Project World · 世界构建项目

Project World 由白羽奈绪发起，旨在**创造、构建、模拟、完善一个完整的架空世界，并将其映射到现实世界**。世界观、故事、科研、软件平台与网站的建设，都行进在这一长期目标之下。

它既是主项目的名字，也是整个项目体系的名字。主项目负责世界本身；所有子项目为这个目标提供工作能力、创作与管理工具，以及现实中的表达和访问入口。

## 一主项目、四子项目

以下定位由白羽奈绪于 **2026-10-03** 明确，其中 K.U.A.T 是新开启的第四子项目。

| 项目 | 定位与职责 | 仓库入口 |
| --- | --- | --- |
| 主项目：Project World | 构造、模拟和完善整个架空世界，维护世界观、设定与故事内容 | [主项目内容说明](IDEA/README.md) |
| 第一子项目：Project IDEA | 为 Project World 开发与对应生物科研建立工作平台，侧重工作、执行与复杂处理 | [Project-IDEA](Project-IDEA/README.md) |
| 第二子项目：Shiroha 网站 | 建立白羽奈绪的个人网站 | [ShirohaV1.1](ShirohaV1.1/README.md) |
| 第三子项目：Project World 网站 | 在网页端介绍 Project World，并承载相应的功能实现 | [World.online](World.online/README.md) |
| 第四子项目：Project K.U.A.T | 建立项目管理、可视化与综合创作平台，承接世界观组织、构思与多 Agent 世界模拟 | [Project-KUAT](Project-KUAT/README.md) |

这些是目标与职责的划分，不代表每项能力已经实现。各项目 README 分别记录现有内容和规划边界。

K.U.A.T 没有可供迁移的代码，将从零开发。第一阶段建立基础平台，包含世界观设定背景、设定卡片、时间线、地图、关系图、插图与共创七项功能。功能参考 Matrees，但专精于 Project World 的实际需求，不以取代 Matrees 为目的；后续所有设定更新都要同步到 Matrees。同步方式仍需核实和设计，详见 [K.U.A.T 项目说明](Project-KUAT/README.md)。
