# Project World 网页视觉规则`n`n## Core（核心）`n`n首页右侧的主几何体统一称为 **Core（核心）**，是 Project World 网络视觉中的中心节点，表达世界连接、同步与持续生长。Core 使用深蓝、蓝紫、青蓝等冷色发光，可由轨道、节点、环、扫描线与规律旋转的立体几何结构共同构成。`n`n## 漂浮几何体`n`n页面允许布置复杂、规律、有空间层次感的漂浮几何体，优先使用轨道、线框、多面体、环、节点和扫描结构。动画应缓慢、规律、可预测，避免无目的抖动和强烈闪烁。配色以蓝紫为主，可少量使用青蓝、淡紫与冷粉紫。不得遮挡主要文案、导航和交互控件；移动端应降低尺寸、透明度或隐藏非必要装饰。
